# 翻訳の更新

`zh_cn.json`、`zh_tw.json`、`ko_kr.json` は追加言語の原稿です。各キーに英語の `source` と訳文の `translation` を保持します。UI、アイテム説明、作り方・用途、進捗、ハンドブック、20篇の記録を含みます。`glossary.json` は用語表です。

英語原文が変わったときは該当する原稿の両フィールドを更新し、`python tools/localization.py` でゲーム用ファイルを生成します。`python tools/gen_data.py` にも同じ生成が組み込まれています。生成はオフラインで動きます。

`python tools/localization.py --check` はキーの網羅性、古い原文、空訳、未処理トークン、書式引数、生成結果との一致を検証します。英語の `%s` を訳文で `%1$s` と書くことは、語順変更時に引数を正しく対応させるために許可されます。FE、mB、座標、数値、ゲーム内IDは意味を変えないでください。

初稿は機械翻訳を基に専門用語と表示形式を調整したものです。母語話者による全文章の校閲は未実施です。改善するときは原稿、用語表、対応する `docs/manual-*.md` を併せて更新してください。
