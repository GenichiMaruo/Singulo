# Singulo

旧文明の触媒工学と回転ブラックホール発電を再現する、Minecraft 1.21.1 / NeoForge 向けの工業mod。
設計は [singulo_plan.md](singulo_plan.md)、装置・素材・レシピの詳細は [singulo_recipes.md](singulo_recipes.md)。

## 構成

| 場所 | 中身 |
| --- | --- |
| `tools/recipes.py`, `tools/config_spec.py` | レシピと設定の唯一の正 |
| `tools/ids.py` | 日本語名 → ゲーム内IDの対応表と、アイテムの種類（実装済み装置・未実装・使用回数つきなど） |
| `tools/gen_data.py` | 上の3つを検証してから `src/generated/` を作る（レシピJSON・タグ・翻訳・モデル・仮テクスチャ・質量値・熱源・Javaの登録表と設定クラス） |
| `tools/balance/` | ゲームバランスの確認用。`analyze.py` が難易度を計算し、`gen_md.py` が `singulo_recipes.md` を作り直す |
| `src/main/java` | mod 本体 |
| `src/generated` | 生成物。手で編集しない |

## 開発

Gradle は JDK 25 で動き（`gradle.properties` の `org.gradle.java.home`）、コンパイルとゲームの起動には Gradle が自動で取得する JDK 21 を使う。

```sh
# レシピや設定を変えたら作り直す（Python は uv 経由。検証で問題があれば何も書き出さずに止まる）
uv run --no-project --python 3.12 --with pillow tools/gen_data.py

# バランスの確認と設計書（singulo_recipes.md）の再生成
uv run --no-project --python 3.12 tools/balance/gen_md.py

# 生成したモデルの確認（1マスからのはみ出しと、同じ向きの面の重なり＝ちらつき）
uv run --no-project --python 3.12 tools/check_models.py

./gradlew build              # ビルド
./gradlew runClient          # ゲームを起動
./gradlew runGameTestServer  # 装置の動作テスト（src/main/java/.../test）
./gradlew runServer -PruinSelfCheck=true  # 4種類の遺構が実際のワールドに生成されるかを確かめて止まる
```

## 進み具合

- 段階1: 熱電発電機、焼成炉、圧縮機（質量モードつき）、電解槽、アーカイブ端末（書き写し・修復・復元）、銅導線が動く
- 段階2: 精密組立台、触媒反応器、極低温冷却塔（マルチブロック）、粒子加速器（マルチブロック）、極低温タービン、SMESセル、宇宙線ミュオン収集器、超伝導ケーブル、ワールドライン・アンカー（小）が動く。触媒の消耗（ティア制約・残量による電力増・不完全反応・失活触媒）も入っている
- 段階3: 量子もつれ合成器、レーザー冷却器（冷却原子トラップの復元も）、残響共鳴器、量子熱機関、慣性スタビライザー、慣性制御ガントレットが動く。触媒を入れる装置（アンカー・スタビライザー・量子熱機関）は共通の画面を持つ
- 段階4: 縮退圧縮炉・C空洞（マルチブロック）、時間結晶育成槽（電力不足で純度＝寿命が下がる）、縮退熱炉（マルチブロック、20 MFE/t）、自動探査機ステーション、SMESモジュール、トポロジカル導線が動く。圧縮ブロックLv2の混成ボーナスも入っている
- 段階5: Pリアクター（点火・降着発電・質量とスピン・運用モードの副産物・蒸発・引力帯と潮汐帯・黒い球と降着円盤の描画）、特異点封入台、ホライズン・バスが動く
- 段階5の特異点技術: イベントホライズン・シールド発生塔（ドームの描画つき）、Tシリンダー（マルチブロック）、ワールドライン・アンカー（上位、コア埋め込み）、メトリック・ドライブ、グラビトン・マニピュレーター（円錐範囲つき）、重力時間膨張ゾーン、ワームホール（生成器・固定化装置・口・ポート）、ハロー捕集器とダークマター、重力閉じ込めタンク、重力レンズの画面効果が動く
- 全段階のアイテム・液体・圧縮ブロックは登録済み
- 遺構: 地表観測拠点・研究棟・封鎖培養施設・最終実験施設がワールドに生成される。保管庫の中身（1回の遠征ぶん）は空になってからゲーム内7日または14日で再生し、警備機ドックから警備ドローンが出撃する。重力波検出器で最終実験施設の方角と距離帯がわかる
- ボス: ホライズン・ウォーデン（最終実験施設の守護機、3フェーズ）。倒すと保管庫の力場が消え、中身が再生すると再び封鎖される
- 遊びやすさ: Singulo ハンドブック（初回にもらえる。章立ての手引き・進み具合・旧文明の記録）、全アイテムの説明（Shift で作り方と使い道）、進捗（L キーの Singulo タブ、43項目）、ホロ投影機とマルチブロックの形成演出、クリエイティブ用の組み立てコマンド
- 装置まわり: 触媒専用スロット、単極子アップグレードの枠（速度×2・電力効率+50%）、面ごとの入出力と自動排出、SMESの画面、上位装置の恩恵を受けている装置に浮かぶエネルギーの流れの模様、段階ごとに意匠の違う32×32の外装とアイテム
- そのほか: 記録片の解読（旧文明の記録20編）、ニュートリノ・スキャナー、重力異常点の歪み、ストレンジレットと磁気瓶、失活触媒のリサイクル、水素漏れの小爆発
- 未対応: 3Dで回せる面の設定画面（今は展開図）、設定カード、設置型のニュートリノ・スキャナー、Iris 系シェーダーパック専用の重力レンズ処理

### 遊びやすさの機能

- **Singulo ハンドブック**: 初めてワールドに入ると1冊もらえる（本と銅で作れる）。右クリックで開き、左の章（はじめに・段階1〜5・マルチブロック・触媒・電力と輸送・遺構・特異点技術・危険）を選ぶ。「進み具合」は段階ごとに達成した目標と次の目標を、「旧文明の記録」は解読した記録を表示する。中身は tools/guide.py・tools/records.py で書く
- **説明**: Singulo のアイテムにカーソルを合わせると説明が出る。Shift を押すと作り方（製作場所と段階）と使い道が出る。説明文は tools/descriptions.py、作り方と使い道はレシピから自動で作る
- **進捗**: 進捗画面の Singulo タブに、段階順の43項目。マルチブロックの形成・遺構の発見・点火・ワームホール・記録の全解読なども達成になる（条件 singulo:milestone）。定義は tools/advancements.py
- **ホロ投影機**: マルチブロックのコントローラに使うと正しい形を投影し、必要な数と足りない数をチャットに出す。足りない場所は小さな見本と水色の枠、邪魔なブロックは赤い枠。スニークして使うと大きさ（冷却塔の高さ・加速器の一辺）が変わる。形はコントローラの正面の反対側（置いたときに見ていた向き）へ伸びる
- **マルチブロックの画面**: コントローラは形が完成するまで画面を開かない（右クリックで「未完成」と出る）。完成後は、どの部品を右クリックしてもコントローラの画面が開く（スニーク中は普通どおりブロックを置ける）
- **形成演出**: マルチブロックが組み上がると、コントローラから近い順に部品の継ぎ目へ光が走り、起動音が鳴る
- **組み立てコマンド**（クリエイティブ・オペレーター用）: `/singulo build <名前> [大きさ]`。見ている向きの数ブロック先に、コントローラが手前・形が奥になるように組み立てる。名前は cooling_tower・particle_accelerator・degenerate_compactor・casimir_cavity・degenerate_furnace・penrose_reactor・event_horizon_shield・tipler_cylinder・wormhole_generator

### 見た目

- **テクスチャ**: 標準は16×16。のっぺりさせず、わずかな濃淡のむらと縁の陰・擦れ（使用感。汚れではない）を入れる。段階色の発光ラインは外装の縁に沿って一周する。段階ごとに外装の意匠が変わる（1 銅の角金具、2 霜と二重の縁、3 菫色の点線の縁、4 金の縁と歯車の刻み、5 黒地に金の角金具と白い光の縁）
- **Singulo HD**: 32×32 のテクスチャは組み込みのリソースパック「Singulo HD」に入っている。リソースパックの画面で有効にすると切り替わる
- **装置の立体**: 基本はふつうの1マスの立方体。働きに意味のある所だけ浅くくぼませる: 炎や反応が見えたほうが面白い装置（焼成炉・電解槽・触媒反応器・時間結晶育成槽・特異点封入台・レーザー冷却器・縮退熱炉）は正面にガラスの窓（奥の中身は稼働中に光る）、排気口・吸気口・放熱フィン（焼成炉と量子熱機関の天面、極低温タービンの側面、熱電発電機の側面）は1ドットの溝、操作盤のある装置（アーカイブ端末・コントローラ類など）は画面を1ドット奥に下げる。定義は tools/shapes.py
- **動く正面**: 段階3以上の装置は、稼働中に正面の絵柄が明るさの波と走査線で動く
- **ケーブル**: 断面は中心に置いた正方形（銅導線2・超伝導4・トポロジカル6・ホライズン・バス8ドット）。座標はすべて整数で、テクスチャは1ドットを1ドットのまま貼る（引き伸ばさない）。段階の違いは帯の模様で描き分ける（芯・リブ・被覆・金の縁など）。当たり判定は見た目と同じ形。まっすぐ敷くと中心も同じ太さの筒、分かれ目では同じ太さの箱になる。段階2以上は電力が流れている間、芯の色が変わる。手に持つと立体の1本になる
- **ブラックホール関係のアイテム**（シンギュラリティ・コア、特異点の種、不安定なワームホールの口など）は、黒い球と傾いた光る輪の立体
- **触媒**は、傾いた結晶柱が寄り集まった、光の当たる面と陰の面のある結晶の塊。アイテムの輪郭は真っ黒にせず、内側の色を暗くした色で描く

### 探索とクリエイティブ

- **探索コンパス**（コンパス・基礎回路・銅）: 右クリックで、選んだ種類のいちばん近い遺構を探して針がそちらを向き、距離が出る。スニーク＋右クリックで探す遺構（地表観測拠点・研究棟・封鎖培養施設・最終実験施設）を切り替える
- **クリエイティブ専用**（クリエイティブタブの最後）: クリエイティブ電源（尽きない電力を隣へ送る）、無限の触媒（減らない。右クリックでティア2〜5）、組み立ての杖（コントローラに使うと、その向きのまま一瞬で組み立てる。スニークで大きさ）

### JEI

JEI が入っていると、装置ごとのレシピ（材料・液体・質量・触媒の使用回数・時間・電力・段階）が見られる。装置のブロックはその分類の触媒として出る。遺構の回収物などレシピのないアイテムには説明のページが出る。マルチブロック装置は、コントローラーか部品を調べると「マルチブロック装置」のページが出る（必要な部品と個数、起動のしかた・燃料・消費・速さや出力・危険）。JEI は任意（入っていなくても動く）。

### 装置の画面

- **触媒スロット**: 触媒を使う装置（精密組立台・レーザー冷却器・C空洞・時間結晶育成槽・特異点封入台）は、進捗矢印の下に琥珀色の枠の触媒専用スロットを持つ。触媒はほかの入力スロットに入らず、触媒スロットにはほかの物が入らない
- **単極子アップグレード**: 画面右の紫の枠に1個だけ挿せる。処理速度×2、電力効率+50%
- **面の設定**: 画面右の小さな展開図のボタンで開く。アイテムと液体のタブで、6面（前・後・左・右・上・下。装置の向きに対する相対）を左クリックで「無効→入力→出力→入出力」と切り替え、右クリックでその面の自動排出（出力スロット・出力タンクの中身を隣へ押し出す）を切り替える。右上の「自動排出 オン／オフ」で、その装置の自動排出をまとめて止められる
- **恩恵の模様**: Tシリンダーの範囲か、イベントホライズン・シールドの守りの中にある装置は、外装にエネルギーの流れる模様が浮かび上がる
- **SMES**: 右クリックで蓄電量と1 tick あたりの受け取り・送り出しを表示する

### 記録・探索・危険

- **記録片**: 遺構の保管庫に1〜3枚入っている。アーカイブ端末で解読すると「解読した記録」になり、右クリックで読むと旧文明の記録が順に1編ずつハンドブックに加わる（全20編）
- **ニュートリノ・スキャナー**: 右クリックで半径24の鉱石（c:ores、他modも）と遺構のブロックの輪郭を、地形越しに10秒間表示する。1回 10 kFE。スニークして電力を持つブロックに使うと充電
- **重力異常点**: 最終実験施設の封印コンソールの上の空間が、重力レンズでゆがんで見える
- **ストレンジレット**: 一辺24以上の粒子加速器を、蓄電が2割を切った状態で回していると、まれに漏れ出す。毎秒1個ずつ周りのブロックをストレンジ物質（質量値100、縮退物質殻の材料）に変え、半径8・512個で止まる。シールドの範囲には広がらない。磁気瓶で封じ込めると、ストレンジ物質4個を回収できる
- **失活触媒のリサイクル**: 触媒反応器で、失活触媒4個から1ティア下の触媒1個（ミュオン触媒はミュオン束2個）
- **水素漏れ**: 水素の入った装置を壊すと、半径3以内に火気があれば小爆発する（設定 hydrogenLeakExplosion）

### マルチブロックの組み方

- **極低温冷却塔**: 3×3の筒を高さ5〜15で積む。各段の外周8マスは冷却塔外壁・冷却塔ガラス・冷却塔ポート・コントローラ（1つ）、中心の列は熱交換コアか空気で、コアは「高さ−2」個以上。高いほど速く、高さ10以上で液体ヘリウムを作れる。パイプやケーブルはポートかコントローラにつなぐ
- **粒子加速器**: 加速管と収束磁石で水平な正方形のリング（一辺8〜32）を作り、コントローラをリングに接して置く。四隅は収束磁石、収束磁石はリング全体の1/4以上。大きいほど速く、磁気単極子も出やすい
- **縮退圧縮炉**: 縮退炉外殻で 3×3×3 の箱を作り、外殻の1つをコントローラにする。中心は空気
- **C空洞**: 5×5×5。下の面と上の面を鏡面プレートで埋め（向かい合う2枚）、間の3段は四隅の柱を縮退炉外殻にする。鏡面の間（中の 3×3×3）は空気（真空）。コントローラは間の段の側面
- **縮退熱炉**: 7×7×9（高さ9）。上下の面は縮退炉外殻で、中心の十字の4か所を縮退熱炉ピストン部にする。間の7段は四隅の柱を外殻にし（コントローラは柱のどれか1つ）、中は空気。燃料は圧縮ブロックLv2（1個で10秒）、時間結晶触媒を消費する

### 段階4のしくみ

- **混成ボーナス**: 圧縮機の質量モードで、圧縮ブロックLv1 を3種類以上の元ブロック（丸石・安山岩・花崗岩など）から作ると「混成」の印がつき、8個で Lv2 にできる（通常は9個）
- **時間結晶育成槽**: 育成は実際に動いた tick で進む（20分）。電力が要求の80%を割ると、その時間の割合だけ純度が下がり、できた触媒の寿命も同じ割合になる
- **自動探査機**: 保管庫を自分の手で開いた遺構が「発見済み」になる。発見した人がステーションを開くと、飛べる遺構（段階4では地表観測拠点）が登録され、ゲーム内半日ごとに探査機が往復して手動遠征の半分の量を持ち帰る。同じ遺構には中身の再生（7日）まで行かない

### 遺構

| 遺構 | 場所 | 中身（1回の遠征ぶん） | 再生 | 警備 |
| --- | --- | --- | --- | --- |
| 地表観測拠点 | 平原・砂漠などの地表 | 観測ログ3〜5、劣化した制御ユニット6〜10 | 7日 | ドローン（弱）×2 |
| 研究棟 | 森・タイガなどの地表。入口の鉄の扉は内側からしか開かない | 量子データ片3〜5、劣化した冷却原子トラップ2〜3 | 7日 | ドローン（中）×3 ×2か所 |
| 封鎖培養施設 | 深層岩の層（Y=−48〜−24）に埋まった密閉施設 | 劣化した時間結晶の種8〜12、培養データ2〜3 | 14日 | ドローン（強）×4 ×2か所 |
| 最終実験施設 | 地表。まれ（重力波検出器で探す） | 劣化したアノマリー・サンプル4〜6、初回だけ休眠した特異点の種 | 14日 | ホライズン・ウォーデン |

保管庫と警備機ドックは壊せない。ドローンは何も落とさない（トラップで稼げないように）。全滅させるとドックは1日後まで出撃しない。

### ホライズン・ウォーデン

最終実験施設の中央の封印コンソールに触れると起動する（保管庫が封鎖されているときだけ）。HP 800（設定 `wardenHealth`）。

| フェーズ | HP | 行動 |
| --- | --- | --- |
| 1 | 2/3 以上 | 白い外装（防御+10）。近接攻撃と、離れた相手への光弾（8ダメージ） |
| 2 | 1/3〜2/3 | 外装が剥がれる。重力攻撃（引き寄せる・浮かせて落とす）を交互に |
| 3 | 1/3 未満 | 重力攻撃に加え、小型の特異点を展開する。半径3.5ブロック・5秒間、中心へ引き寄せ、防具を無視する潮汐ダメージ（4／0.5秒） |

- 挑戦者がいなくなる（死亡・施設から24ブロック以上離れる）と、5秒後に全回復して封印に戻る（`wardenResetOnLeave`）。保管庫は封鎖されたまま
- 倒すと保管庫の力場が消える。中身（14日で再生）が戻ると再び封鎖されるので、再挑戦はその周期ごと
- ボス扱い（`#c:bosses`）で重力耐性。ガントレットなどの重力操作は効かない

### Pリアクター

- **組み方**: 炉心の中心 C を決め、C を通る直交3平面（XY・YZ・XZ）に半径6の円環を、途切れずに辺でつながるように作る（各48ブロック）。3本が交わる軸上の6点（C±6）はジャイロ駆動部、各円環の斜め45°の点（計12）は抽出ポート、残りは炉殻ブロック。中心の 3×3×3 は空気（真空の炉心）。炉心制御装置は C の5ブロック下（炉心の真下）。必要数は炉殻120・ジャイロ6・ポート12でレシピと一致する（炉殻は縮退物質殻1個から12枚）
- **点火**: 種のスロットに特異点の種（2回目以降はシンギュラリティ・コア）を入れて「点火」を押し、10秒以内に 50 GFE をポートかコントローラに注ぐ（毎tick 250 MFE 以上 = ホライズン・バスが必要）。失敗すると注いだ電力は失われるが種は残る
- **発電**: 燃料は質量ペレット（1個 20 GFE × 降着効率）。降着効率はスピンから実在の最内安定円軌道の式で決まる（無回転 5.7%、最大 42.3%）。投入は炉心質量1000ごとに毎秒1個まで（エディントン限界）。蓄電（40 GFE）の減った分だけ投入し（負荷追従）、炉心を保つため限界の3%は常に投入する。炉心質量5000・最大スピンで約 2.1 GFE/t
- **質量とスピン**: 投入した質量の10%が炉心に加わる（500→上限5000）。ホーキング放射で小さいほど速く痩せ、100 を割るとバーストして炉心が消える（外殻の外は壊さない。設定で変更可）。スピンは「スピン目標」（0・0.5・0.9・0.99・1.0）まで、蓄電から最大 100 MFE/t を使って上げる
- **抽出装置と副産物**: ジェット・コレクター（発電中、1基につき1分に1個のジェット凝縮体）、Hコレクター（炉心質量150〜400で5分に1個のH凝縮体）、エルゴスフィア・リング（スピン0.7以上・質量400〜2000で1分に1個のエキゾチック物質、スピンが0.02減る）
- **危険**: リングの外は半径24ブロックまで弱い引力（歩けば逃げられる）。リングの内側に入ると強い引力で中心へ吸い込まれ（逃げられない）、半径4ブロックの潮汐帯では防具を無視するダメージを受ける。事象の地平線（黒い球）に触れたものは、どんな体力・耐性・無敵・不死のトーテムでも必ず死ぬ（専用のダメージ singulo:event_horizon。それでも残れば体力0、さらに残れば世界から取り除く）。アイテムなど生き物でないものは飲み込まれて消える。クリエイティブとスペクテイターのプレイヤーは引き寄せも消滅も受けない（設定 blackHolePullStrength・blackHoleInnerPullStrength・eventHorizonKill）
- **重力時間膨張ゾーン**: 炉心がある間、引力帯の中では装置の処理が ×0.8、触媒装置の触媒の減りが ×0.5 になる（設定 timeDilationEnabled）

### 段階5の特異点技術

- **イベントホライズン・シールド発生塔**（3×3×9）: シールド発生塔コアを底の中央に置き、周りの8マスと、コアの上の柱8段、柱の根元（高さ1）の四隅を縮退炉外殻にする（計20個）。半径32の球を守り、電力は半径²×16（16,384 FE/t）。時間結晶触媒で「範囲内の爆発を打ち消す・外からの爆発で範囲内が壊れない・モブが荒らせない」、シンギュラリティ・コアではさらに「敵対モブが湧かない（スポナーは除く）・入ってきた敵対モブを押し返す（ボスは除く）」
- **Tシリンダー**（3×3×7）: Tコアを底の中央に置き、周りの8マス、上の層（高さ6）の中央以外の8マス、間の四隅の柱（高さ1〜5）を縮退炉外殻にする（計36個）。中央の高さ1〜6は空気（白い円柱が回る）。時間結晶触媒・エキゾチック物質（1分に1個）・100 kFE/t で動き、半径8の中の装置・かまど・醸造台・作物を ×2 にする。範囲内の触媒装置は触媒の減りも ×2。時間膨張ゾーンと重なると打ち消し合う
- **ワールドライン・アンカー（上位）**: 半径は触媒のティア−1（ボース凝縮2・時間結晶3・コア4チャンク）。シンギュラリティ・コアを持って2回右クリック（5秒以内）すると埋め込み、触媒も電力も使わず半径5を保つ。コアは取り出せず、壊しても戻らない
- **メトリック・ドライブ**: 持ち物に入れておくと効く（Curios には依存しない）。右クリックで 停止→低重力（重力×0.25・落下ダメージ×0.25）→無重力（飛行）→高重力（重力×1.5・ノックバック無効）。動いている間、エキゾチック物質を10分に1個使う
- **グラビトン・マニピュレーター**: 慣性制御ガントレットの完全版（射程は設定 manipulatorRange、既定24ブロック。ガントレットは gauntletRange、既定12ブロック）。操作は**左クリック長押し**で今のモードを使う（叩いたりブロックを壊したりはしない）。浮遊モードで持ち上げている間に**右クリック長押し**で力をため（最大2秒、ためた1tickごとに 2,000 FE）、**離すと視線の向きへ勢いよく投げ飛ばす**。スニーク＋右クリックでモード切替。キー割り当て（既定 G）で「視線上の1体」と「前方の円錐（半角25°・最大8体、電力は対象の数だけ）」を切り替える。浮遊（HP制限なし）・牽引（射程24、ドロップアイテムも）・斥力（半径6のモブを押し出し、飛び道具をそらす）・圧壊（動きを止め毎秒「2＋最大HPの5%」、防具無視）。ボスと重力耐性は浮遊・牽引・斥力を受けず、ボスへの圧壊は毎秒10まで。電力 400 FE/t と、エキゾチック物質を使用5分ごとに1個使う（持ち物の重力閉じ込めタンクのダークマター 250 mB でも代わりになる）
- **ダークマター**: ハロー捕集器を稼働中の炉心から16ブロック以内に置くと、炉心質量100ごとに毎秒1 mB 集まる（2 kFE/t）。捕集器の中では毎秒2%漏れるので、隣の重力閉じ込めタンク（64,000 mB、中身があると 500 FE/t、電力が切れると毎秒1%漏れる）へ送る。タンクは壊すと中身ごとアイテムになる。炉心制御装置か抽出ポートに流し込むと、エディントン限界を受けずに 1 mB あたり質量0.01 が炉心に加わる（発電はしない）
- **ワームホール**: 
  1. 生成器（3×3×3）: ワームホール生成器コアを底の中央に置き、残りを縮退炉外殻で囲む（計24個、中心と天井の中央は空ける）。毎tick 100 MFE（設定 wormholeGeneratorPower）を10秒続けて受けると、一対の不安定な口ができる（画面か搬出で受け取る）。60秒以内に固定化しないと消える。外殻の代わりに入出力口をどこにでも置ける（電力の搬入と、できた口の搬出）
  2. 固定化装置: 不安定な口とエキゾチック物質（口1つに2個）を入れると、5秒で設置できる「ワームホールの口」になる
  3. 口を置き、エキゾチック物質を入れる（3×3 で5分に1個、喉の面積に比例、別ディメンションとつなぐと3倍）。スニーク＋右クリックで喉の目標（3×3・5×5・7×7）を変える。燃料が切れると30秒ごとに喉が縮み、最後は崩壊して消える
  4. 口から8ブロック以内に置いたワームホール・ポートは、向こう側の口の近くのポートの隣の装置と直結する（電力・アイテム・液体）。1 tick の帯域は喉の大きさで決まる（3×3: 64 MFE・8個・1,000 mB）。向こう側のチャンクは読み込まれている必要がある（アンカーを使う）
- **重力レンズ**: 炉心とワームホールの口の周りの景色を、点質量レンズの式で画面上でゆがめ、縁にアインシュタインリングを描く（クライアント設定 gravitationalLensing で切れる）
