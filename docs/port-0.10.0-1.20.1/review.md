# 0.10.0 / Minecraft 1.20.1 移植と検証

移植元はPR #34のマージコミット `b2bf9034a5cb6b0d69edd68fbf1ecadaf8586c29`。対象は共有ブランチ `1.20.1`、Forge 47.4.26 / NeoForge 47.1.106、Java 17。

- 発電・蓄電、材料の用途、レシピ副産物、容器、待機理由、マルチブロックのポート修正を移植。
- 308レシピについて材料・数量・時間・電力・段階を移植元と正規化後のハッシュで照合。
- 5言語の説明とGUI修正を反映。GUI検証は142画面、機械ヘッダー80か所、言語切り替え後の数字5件、既存の持ち物欄105点を検査する。
- 1.20.1固有のNBT保存とレシピ同期に対応。副産物のJSON・パケット往復、流体容器の保存・通信往復を追加検査する。
- 0.9.0で修正したクライアント設定のスレッド制御とテスト構造の隔離を維持。
- 公開処理は両ローダーの全422必須GameTest、実Mekanism各2件、GUI証跡と同一ツリーの照合に成功した成果物だけを昇格する。GitHub ReleasesへのJAR添付は行わない。

ローカル初回検証で新しい通知テストが1.20.1標準のモックプレイヤーの未接続チャンネルに触れることを確認し、既存の互換ヘルパーへ変更した。通知の一度だけの判定は維持する。

最終結果はPRの検証コメントと公開ワークフローに記録する。

ローカルForgeコア検証は291件すべて成功。1.20.1側の既存互換テストと0.10.0追加分を含む実際の完了ログに合わせ、コア291件・全体422件を必須の件数へ設定する。件数の下限を緩めず、正確な一致を公開条件とする。
