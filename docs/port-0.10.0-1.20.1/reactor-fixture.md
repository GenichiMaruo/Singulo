# 公開後の追加CIで見つかった試験室の環境依存

PR #35の検証は全14ジョブ成功したが、マージ後のrun 39246362583ではForgeの `ergosphereYieldsExoticMatterAndSpinsDown` が一度失敗した。炉心の質量とスピンは正常範囲だったが、副産物の進行が停止していた。

上部へ水源を置いた再現試験では、`formed=false` と炉心3×3×3内の水を確認し、同じ副産物出力待ちが停止した。リアクターが真空を失えば加工を止めるのは実装どおりであり、変更対象は試験環境である。元のCI失敗には炉心内ブロックの記録がないため、元の失敗原因が水だったとまでは断定しない。

以前からペレット供給試験にだけあった64×15×64室の防壁を共通の `build` へ移し、ほかのリアクター試験も周囲の流体・落下物から隔離する。副産物試験には天井上の水源を残し、防壁がないと失敗した同じ処理が、防壁ありで成功することを検証する。出力とスピン低下の判定、1200 tickの製品処理、2000 tickの上限は変更しない。

既存の全21リアクターテストと全422件の必須件数を維持。製品の発電処理、構造条件、レシピ、バランスの変更はなく、公開済みタグやJARの差し替えは行わない。
