# 0.16.0 — 液体パイプ

対象はMinecraft 1.21.1 / NeoForge。1.20.1への移植は未実施。アイテムのパイプは作らない（面の設定、ホッパー、ドローン、アンドロイドで運ぶ）。

## 仕様

- 段階1。銅インゴット6個とガラス3個から作業台で16本。種類は1つで、方向の設定はない。
- 液体は溜めない。つながったパイプのまとまり（`FluidPipeNetwork`）が5 tickごとに、口どうしで直接受け渡す。1つの口が1周期に出せるのは4,000 mB。
- 液体ごとに、出すだけの口 → 受けるだけの口 → 出し入れできる口（タンク）の順に配る。タンクからは受けるだけの口へしか出さないので、タンクどうしで行き来し続けない。
- 出し入れする面は装置の面の設定（capability）で決まる。マルチブロックは搬入出ポートでつなぐ。
- 隣の水源・溶岩源は、受け手に1,000 mBの空きがあるときだけ汲む。源は1個なくなる。
- 読み込まれていないチャンクは強制的に読み込まない。

## 守っていること

- 装置の空の入力タンクはどの液体でも入るので、パイプからはレシピで使う液体だけを入れる（`PipeFluidFilter`）。手や他modからの搬入は変えていない。
- 極低温タービンとミュオン核融合炉は入力タンクをそのまま公開しているので、パイプからは抜かない（`PipeInputOnly`）。手のバケツでは取り出せる。

## 検証

`FluidPipeGameTests`（13件）。水、溶岩、登録した液体・ガス7種のすべてを、実際に使う口まで届けて確かめる。冷却塔とカシミール空洞はポート経由。ほかに、総量の保存、使わない液体の拒否、入力タンクを抜かないこと、タンクどうしで動かないこと、水源の扱い、切断とつなぎ直し、面の設定を確かめる。見た目はゲーム内で確認済み。

## 制限

- 他modのパイプから液体パイプへ直接は流し込めない（パイプはcapabilityを公開しない）。装置やタンクを挟む。
- 移設レンチのケーブル撤去モードはパイプに効かない。
- 実チャンク境界での読み込みと解放、多人数、大規模な配管の負荷は未確認。
