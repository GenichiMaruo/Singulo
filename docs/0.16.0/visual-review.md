# 0.16.0 外観変更後のレビュー

対象は Claude による12コミットの変更を含む `8d3eccd248e2fb7cea44848fb2e30e7adc9dc4ab`。
既存のPC作業とは別のworktreeで確認した。ドラフトPRは [#62](https://github.com/GenichiMaruo/Singulo/pull/62)。

## 発見と修正

1. **スプール両端の頂点順**。端面の法線は外向きだが頂点順が内向きで、`entitySolid` のカリングによって外から消える。
   実際に出力されるメッシュの外積と法線の内積が修正前は負（最初の端面で約 -1.132）になることを再現した。
   両端を外から見て反時計回りへ修正。3つの回転角で側面・両端の計144面を検査し、両端からの実画面も撮影する。
2. **蓄電値とポートの重なり**。SpindleでShift詳細表示を有効にすると `19,999,000,000` の表示・ホバー領域が左ポートと重なる。
   枠内の値は常に短縮し、完全な同期値と容量はツールチップに表示する。蓄電庫の電力量・入出力にも同じ方針を適用した。
   5言語それぞれで通常3画面、Shift表示、電力・左右ポートへのホバーの計7画面を描画し、実フォントから得た全ホバー領域が重ならないことを検査する。
3. **シェーダー再読み込み時のリーク**。色用と深度用の別インスタンスを同じ名前で登録していた。
   Minecraftのレジストリは名前をキーにして最後の1つだけを保持・解放するため、先のインスタンスが管理外になる。
   深度用に別のJSON名を与え、GLSL本体は共有する。実クライアントで4インスタンスが別々に登録され、リソース再読み込み後は全て置き換わり旧GLプログラムも解放されることを検査する。
4. **配管の矢印が管に埋まる**。配管の半幅は3/16ブロックだが、元の矢印の広がりは約0.17ブロックで、大部分が不透明な管の中に隠れる。
   視点側の2外面へ表示位置を移した。通常の深度判定を維持し、壁越しには表示しない。
   1方向あたり256頂点の描画量を維持し、6方向×流入・流出×2視点の24ケースで全頂点が管の外にあることを検査する。

```sh
./gradlew -I tools/review/cosmic.gradle runClient
./gradlew -I tools/review/cosmic.gradle runClient -PwithSodium -PwithDistantHorizons
```
