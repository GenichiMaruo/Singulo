# 0.17.0 / Minecraft 1.20.1

基点は `1.20.1` の `ae6dcb48`。レビュー済み 1.21.1 版 `cae7c17f`（マージ `1b6a4a4b`）の 0.17.0 機能と不具合修正を移植する。Forge 47.4.26 / NeoForge 47.1.106、Java 17。

## 移植差分

- 液体パイプ四段階、液体カプセル・発着ポート、倉庫、コラプサー内張り、航路標識、投射物のワームホール通過を旧 API へ移植。
- 1.20.1 の NBT・capability・登録 API を使用。倉庫と液体ポートは実際の破壊・アイテム配置経路で内容を保持する。
- 旧 Item API にスタック別のコンテナ制約がないため、既存の挿入制約 mixin を拡張し、内容を持つ倉庫の入れ子を防ぐ。実際のスロット・ホッパー・InvWrapper・Bundle 挿入を回帰検証する。
- 旧 ServerLevel の投射物 tick 呼び出しだけを差し替え、通過成功時も profiler と乗客処理を保つ。次元間移動は Forge ITeleporter を使用する。
- 描画は旧 BufferBuilder・FluidType API を使用。ブロックアイテムのツールチップを BlockGetter シグネチャと実際の委譲経路に合わせる。
- 液体ポートの capability を面ごとの安定したハンドラーにし、面設定変更時の即時再取得でも古い optional が孤立しないように修正。保持済みハンドラーも現在の設定を参照する。
- 生成元を維持し五言語を再生成。411 レシピはレビュー済み 1.21.1 のデータを独立に旧形式へ正規化した manifest と照合する。
- 配布 JAR のコンパクト化を継承し、Java 17 の remap 出力を配布する。HD 任意リソースは本体へ同梱しない。

## 検証

通常 GameTest の宣言は両ローダー各751件、実 Mekanism 用2件。検証ツール単体78件、レシピ411件、五言語3539キー、モデル・ゲーム文言・advancementの静的検証が通過した。分野を入れ替えた独立レビューで移植固有の capability 無効化問題を発見・修正し、再レビューでブロッカーなし。初回実行で検出した `c:leathers` → `forge:leather` の変換漏れも生成元で修正した。実行・正式 CI の確定結果は完了時に追記する。

## 検証の範囲

大規模な実プレイヤー同時接続、長期稼働、任意の外部 mod の組合せを保証するものではない。公開には四つの正式 CI ジョブと同一ツリーの検証済み配布物を必要とする。Modrinth への公開は今回行わない。
