## 再検証での修正

1.20.1のNbtUtils.writeBlockPosはCompoundTagを返す。指令台のlinksをIntArrayTagの一覧として読むと、再読込後に資材口・棚・納品口へのリンクを失うため、一覧の型をCompoundTagに修正し、位置一覧の往復検査を追加した。

言語変更時の検索インデックスはLevelなしでツールチップを生成するため、カードの説明はLevelに依存しないNBT読込を使う。Forge版の実クライアントで15枚と完了マーカー、全3タブのPNG画素検査が成功した。

1.20.1のGameTestではチャンクの準備を20 tick待つ。自動注文が別試験の空いている個体を選ばないよう、追加の自動化試験を別バッチにし、模擬プレイヤーの試験終了時にその工場の注文・個体を片付ける。元の期待値や必須判定は維持する。これは試験環境のみの変更で、製品のティックや消費量は変更しない。

全体試験で、収穫対象の2つの作物が空気になっていたため、畑の照明・水・土壌を明示し、照明更新を待ってから成熟した作物を植える。納品2個・2か所の植え直しという判定は維持する。終了した試験の装置・敵が次の試験へ影響しないよう、試験領域のブロックエンティティとプレイヤー以外のエンティティを終了時に片付ける。共有チャンクの強制読込は外さない。

リンク保存の回帰テストは、一覧のコピーを書き換えるのではなく、実際の作業位置カードで納品口を接続した後に保存／読込する。
