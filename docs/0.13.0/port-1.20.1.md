# 0.13.0 — Minecraft 1.20.1移植

対象はForge 47.4.26 / NeoForge 47.1.106、Java 17。移植元は1.21.1版0.13.0（`789907d7`）。他の0.13.0バランス・性能レポートは移植元の測定記録であり、本版の測定結果とは区別する。

## 互換性

- 360レシピを1.20.1形式に正規化し、移植元とハッシュ比較する。`recipe-parity-1.20.1.json`が基準。
- アイテムと装置の状態は1.20.1のNBT方式で保存する。SMESの定形アップグレードは蓄電量を継承し、元アイテムを変更しない。
- レシピ同期の触媒ティア追加に合わせ通信プロトコルを5へ更新し、旧版との接続を拒否する。クライアント・サーバー両方を更新する。
- 隣接在庫のキャッシュはForgeのLazyOptional無効化を監視し、装置交換とチャンク破棄に追従する。
- 探査回収物の待機キュー、触媒残寿命と小数の進捗を保存・復元する。

## テストとCI

22ジョブを4ジョブへ整理。両ローダーで通常GameTest全589件とGUI全242画面を実行し、共通実装のMekanism連携2件・描画連携はForgeで一度実行する。PRとマージ後pushで同じ検証を重複起動しない。

テスト名のソース一覧・実登録・各完了結果を照合する。テストやレビュー用クラス、テスト構造テンプレートは製品JARに含めない。公開は同一Gitツリーの検証済み成果物を再ビルドせず使用する。
