# Singulo 0.13.0 — Minecraft 1.21.1 / NeoForge

- Improved large Android production orders, workbench buffering and machine-network performance.
- Prevented product overflow and preserved pending probe cargo across saves.
- Probes now wait without consuming resources when output is full or ruins are regenerating. Singularity Cores unlock research-building collection.
- Added shaped SMES construction and charge-preserving upgrades from existing cells.
- Reduced the default time-crystal growth duration to eight minutes and increased Time Crystal Module batch output to four.
- Added projection-core and degenerate-nucleus reconstruction after their initial progression unlocks.
- Primordial Seeds now require one use of a restored anomaly sample.
- Improved test coverage, translations and documentation.

Existing server settings are preserved. Set `timeCrystalGrowthTicks=9600` to use the new eight-minute default in an existing world.

JAR downloads are available on CurseForge only.
