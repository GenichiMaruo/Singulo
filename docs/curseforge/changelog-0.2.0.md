## Singulo 0.2.0 Beta

### New content
- Sealed ruin containers with stage-specific keys, unlocking effects and sounds, and rare rewards: Overclock Chips, Gravity Boots, Catalyst Stabilizers, Dimensional Pockets and sealed records.
- Neutrino Scanner sensitivity levels and sensitivity modules.
- A support button in the in-game handbook.

### Improvements and fixes
- Redesigned ruins and adjusted generation frequency. Observation Posts remain on the surface; the other ruin types are underground. Added ruin placement commands and progressive compass tuning.
- Machine power switches, recipe selection for recipes without ingredients, per-tank side configuration, coloured tank borders, animated fluids and gases, and overclocking.
- Energy cables now pulse along paths that actually carry power. Removed the Horizon Bus transfer cap.
- Fixed Neutrino Scanner outlines not appearing through terrain.
- Prevented friendly fire between the Horizon Warden and Security Drones. The Warden can now deflect black hole bombs.
- Updated creative tab ordering, animated item textures, compass needles, sounds and registered content. Data generation is now deterministic.
- Updated player manuals, recipe images and five-language translations.

### Compatibility
- Minecraft 1.21.1, NeoForge 21.1.256, Java 21. JEI remains optional.
- Ruin generation changes apply to newly generated terrain; existing terrain is not regenerated automatically.

This is a Beta release. Please report issues on the [issue tracker](https://github.com/GenichiMaruo/Singulo/issues).
