# Singulo 0.22.0 (Minecraft 1.21.1 / NeoForge)

## What's New

- New androids have been added and can now be found in-game.
- Rebuilt underground ruin antechambers with more detailed facility layouts and observation areas.
- Improved ruin placement to avoid nearby structures and made the Explorer Compass point above supported ruin entrances.
- Refined visual effects around gravity remnants.

Ruin generation changes apply to newly generated chunks.
