# Singulo 0.16.0 — Minecraft 1.20.1 / Forge and NeoForge

## Features

- Add the Fluid Pipe, so every liquid and gas in the mod can be moved without other mods. Pipes connect on their own, carry any mix of fluids, send outputs to the machines and tanks that use them, and draw from adjacent water and lava sources.
- Add the Suspension Reservoir, a 7×9×7 facility that hangs 16,000,000 mB of fluid from an octagonal crown as a single swelling drop.
- Add the Nuclear Pasta Accumulator, a 7×9×7 press storing 8 TFE. As it charges, its plates close and the nuclear pasta inside changes from drops to rods to sheets.
- Add the Tidal Spindle, a 7×8×15 machine that draws Tidal Filament from a confined black hole through narrowing rings onto a turning spool.
- Add the Wormhole Seam Upgrade, which stitches a walkable opening between a wormhole's two mouths, and the Collapsar Parallel Cassette, which runs up to four Jet Forge batches together.
- Survey Glasses now show the direction, fluid and blocked state of Fluid Pipes.

## Fixes

- Correct black-hole distortion appearing through solid foreground blocks in Fabulous graphics.
- Remove unused internal UI and fluid helpers while preserving public APIs and saved data.

## 追加

- 液体パイプを追加しました。このmodの液体とガスをすべて、他modなしで運べます。置くだけでつながり、何種類でも1本で流せて、出口の液体を使う装置やタンクへ送り、隣の水源や溶岩源からも汲みます。
- 重力懸垂タンクを追加しました。7×9×7 の設備で、八角の冠から 16,000,000 mB の液体を1つのしずくとして吊ります。
- 核パスタ積層蓄電庫を追加しました。7×9×7 の圧縮機で 8 TFE を蓄えます。充電につれて押し板が締まり、中の核パスタが粒、棒、板と形を変えます。
- 潮汐紡糸機を追加しました。7×8×15 の設備で、封じ込めたブラックホールから潮汐繊維を引き、細くなるリングに通してスプールに巻きます。
- ワームホールの両端を歩いて通れるよう縫い開くワームホール縫合拡張と、鍛造炉で最大4バッチを同時に加工するコラプサー並列カセットを追加しました。
- 測量メガネで液体パイプの流れの向き、液体の種類、詰まりが見えるようになりました。

## 修正

- Fabulous描画で、手前の不透明なブロックをブラックホールの歪みが貫通して見える問題を修正しました。
- 未使用の内部UI・流体処理を整理しました。公開APIと保存データの互換性は維持しています。
