# Singulo 0.16.0 — Minecraft 1.21.1 / NeoForge

## Features

- Add the Fluid Pipe, so every liquid and gas in the mod can be moved without other mods. Pipes connect on their own, carry any mix of fluids, send outputs to the machines and tanks that use them, and draw from adjacent water and lava sources.

## 追加

- 液体パイプを追加しました。このmodの液体とガスをすべて、他modなしで運べます。置くだけでつながり、何種類でも1本で流せて、出口の液体を使う装置やタンクへ送り、隣の水源や溶岩源からも汲みます。
