# Singulo 0.21.1 — Minecraft 1.20.1 / Forge and NeoForge

- JEI no longer stops registering Singulo item descriptions and acquisition hints when a third-party recipe returns a null result. See [#85](https://github.com/GenichiMaruo/Singulo/issues/85).

- 他のModのレシピが null を返しても、JEIでSinguloのアイテム説明や入手方法の登録が止まらなくなりました。
