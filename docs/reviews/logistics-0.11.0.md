# 0.11.0 装置の移設・搬出・研究所の立坑

## 操作と仕様

- **移設レンチ**: 鋼鉄インゴット3・銅インゴット2・基礎回路1。消耗しない。スニーク＋右クリックで装置を1個回収する。白い外装、銅の継ぎ手、水色の表示灯を持つ専用16×16テクスチャ。
- 加工装置、熱電発電機、水素燃料電池、極低温タービン、ミュオン核融合炉、SMESセル／モジュール、宇宙線ミュオン収集器、探査ステーション、縮退熱炉、量子熱機関、慣性安定器、シールド塔、Tシリンダー、大小のワールドライン・アンカーに対応。
- 内部アイテム、液体、電力、処理進捗、装置固有の保存設定を保持。再設置時の正面方向は通常の設置操作に従い、面設定は正面基準で引き継ぐ。内容入りの装置は重ならない。
- マルチブロックはコントローラを回収し、部材は残す。古いポートの接続を解除し、再設置先で構造を判定し直す。アンカーの旧位置のチャンク券と利用枠も解放する。
- 装置を閲覧中のプレイヤーのGUIを閉じてから回収する。持ち物が満杯なら、保存データ付きの装置を1個落とす。通常の破壊で中身を落とす処理とは重複させない。
- Pリアクター、ワームホール機器、アンドロイド設備など、上記に含まれない装置は回収対象外。未確認の特殊装置へ一律に保存処理を適用しない。

## 搬出の変更と原因

1. 全体スイッチと各面の自動排出フラグが両方必要だったため、全体をオンにしても全ての面のフラグがオフだと搬出されなかった。新規装置は**全体オフ・出力可能な面は準備済み**に変更。旧設定で出力可能な自動排出面が一つもない場合も、全体をオンにすると準備する。既存の面設定・保存済み全体スイッチは維持する。
2. マルチブロック搬入出ポートが隣接する別構造のポートまで除外していた。異なるコントローラにつながるポートを搬出先として認め、自分自身への搬出は引き続き除外する。
3. 面設定の立方体にカーソルを合わせると、その面に実際に隣接するブロック名を表示。装置の向きを考慮し、長い名前は画面内に折り返す。

既存ワールドで明示的に自動排出をオンにしていた装置を、更新だけでオフにはしない。

## 研究所

- 17×11×17の**貨物昇降室**を必須部屋として追加。中央3×3の荷台、床の警戒線、吊り荷用の支柱・レール・鎖・フック、トロッコ線路、コンベア、樽、操作端末を配置。中央の昇降空間と扉の進入路を確保する。
- サブの搬入出立坑を、この専用室の天井へ固定して接続する。従来の必須室と任意室の抽選を残し、必須室を1室増やす。
- 生成する施設には主立坑と搬入出立坑を各1本含める。搬入出立坑を省略する分岐を削除。斜面で浅くなる場合は設定された深度の範囲で施設全体を下げ、両方を作れない候補や水上の口は生成候補から外す。
- 溶接蓋とボス撃破後の解除は従来の仕様を維持。変更は新規生成の研究所に適用される。
