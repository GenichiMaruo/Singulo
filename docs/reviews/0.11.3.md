# 0.11.3: DHの通常描画とドローンの調整

ブランチ: `bugfix/0.11.3`。0.11.2のマージ結果から作成。

## DHの黒い遠景

対象はDistant Horizons 3.3.3 / Minecraft 1.21.1 / NeoForge。ユーザー環境のJARはModrinth版 `9w34y8ai` と同じSHA-1 `4357b4d19fab818780c94f0e43dad1cc931634b2`。

DHの `LightMapWrapper_neoforge.uploadLightmap()` は画像の幅・高さでGPUテクスチャを確保する。一方、通常描画の地形／汎用シェーダーは16段階の自然光を0〜1の正規化UVで参照する。Singuloが16×512に拡張した画像を渡すと、人工昼光のバンクや未使用行を読み、遠景が黒くなる。

任意の互換Mixinで、DHへアップロードする画像が16×512の場合にだけ、最初の16×16の自然光領域を一時画像として渡す。元画像は変更せず、一時画像はアップロード後に解放。Sodiumや通常描画の人工昼光は従来どおり元画像を使う。シェーダーパックが供給するライトマップIDの設定処理は変更しない。DHはコンパイル／実行時の必須依存にしない。

開発用の `DistantHorizonsReviewHarness` は、DHの実レンダラーが保持するGPUテクスチャを読み戻し、サイズ16×16と自然光256画素の一致を検査する。晴天正午・雨天深夜・消灯・再点灯の各段階で実施する。互換Mixinを外すとサイズ検査で失敗することも確認した（`build/review-0113-dh-baseline.log`）。DH単体の修正版では全段階成功し、従来の84,000画素のパネル照明PNG比較も一致（`build/review-0113-dh-fixed.log`、`build/review-0113-dh-shots/`）。

CIのSodium照明検証にも、固定バージョンのDHを同時導入してGPUライトマップの検査を必須にする。シェーダーパック有効時の見た目がバニラの晴天正午と一致することまでは保証しない。

DH 3.3.3＋Sodium 0.6.13＋Iris 1.8.12＋BSL v10.1.8を有効にした実クライアントでも、コピーしたワールドで5回の入場を完走した。ログでBSLの有効化を確認し、描画の継続・保存・再入場が成功（`build/review-0113-dh-bsl.log`）。BSL使用時の遠景全域の画素比較や、すべてのシェーダーパックの互換性を保証する検査ではない。

## ドローン

警備機ドックの出撃数を段階1=2体、段階2=3体、段階3=3体にする。出撃済みの個体を強制削除せず、次の出撃から適用する。

ドローンは共有クラス `HorizonBolt` の既定値（魔法ダメージ）を使っており、防具を無視していた。ドローンの発射時に既存の `armored(true)` を指定し、通常の飛び道具として防具で軽減する。突進・パルスは元から通常の近接ダメージ。ボスの光弾は今回の対象外とし、変更しない。

出撃の既存GameTestを全3段階に拡張。ドローン自身に実際に発射させた光弾を当て、無防具より防具20・強靭度8の対象へのダメージが半分未満になる回帰テストを追加する。

## 最終確認

- 必須GameTest 513件が全件成功（`build/review-0113-gametest.log`）。公開処理のPythonテスト10件も成功。
- DH単体・DH＋Sodiumのシェーダーなし構成で、GPUの自然光256画素の一致を全4段階で確認。後者ではSodiumの241段階の頂点復元・自発光モデル検査も成功（`build/review-0113-dh-sodium-fixed.log`）。
- 両構成のパネル照明は、晴天正午・点灯中の雨天深夜・再点灯で84,000画素が一致し、消灯時は暗くなる。
- DH＋Iris＋BSLは5回の入場を完走。シェーダーの有効化と例外・OpenGLエラーのない実行を確認。
- ワークフローYAML・Mixin JSONの構文を確認。通常ビルドに戻し、開発用クラスが配布JARへ混入していないことを配布検査で確認した。

この修正ではpush・PR作成・マージ・公開は行わない。成果物は `build/libs/Singulo-0.11.3-1.21.1N.jar`。
