# レイリー散乱パネルの日光の確認・修正

対象: `feature/0.11.0`。修正前の基準は `17605e3`。版番号、消費電力20 FE/t、蓄電容量4,000 FEは維持する。

## 結論

修正前は晴天・正午の太陽光と同等ではなかった。通常のブロック光15を出し、32ブロック以内の真下の日照センサーだけを特例で15にしていた。密閉した部屋には空の光が届かず、夜間の光の色・実効光量・日光で燃える判定も正午と異なっていた。

点灯中のパネル下へ、自然光と区別して保持する人工の日光を追加した。遮蔽物のない直下では空の光量15・実効光量15となり、夜間と悪天候による暗さを受けない。描画にも標準の晴天・正午の光の色を使う。

| 確認項目 | 修正前 | 修正後 |
| --- | --- | --- |
| 光の種類 | ブロック光15 | 空の光15。従来のブロック光源は廃止 |
| 夜・悪天候の実効光量 | ワールドの暗さに依存 | 人工日光の寄与には暗さを適用しない |
| 光の色 | ブロック光や夜の光マップの色 | 標準の晴天・正午の計算結果 |
| 高さ | 日照特例は上方32ブロックまで | 読込済みのワールドの下限まで直射光が届く |
| 遮蔽物 | 固体判定だけで日照特例を遮る | 不透明度、上下の面の形状、水による減衰、周囲への拡散を計算 |
| 日照センサー | 直下だけ15、反転0 | 直射15。側方や影では減衰した値。より強い自然光も維持 |
| 夜間の日焼け | 夜なので燃焼しない | 日光で燃えるMobが人工日光を認識。水や防具などの通常条件は維持 |
| 消灯・撤去・チャンクの出入り | ブロック光の更新のみ | 人工日光も破棄・再構築し、クライアントの該当区画を再描画 |

ガラス越しの直射は15、水に入った位置は14、その下への拡散は13となる。不透明な床や連続した半ブロックの天井は光を遮る。単独の遮蔽物の下には、周囲から減衰した光が回り込む。製作したパネルと研究所のパネルは同じ照明処理を使う。

## 実装上の確認

- 光の照会は、標準のSKYと人工日光の最大値を返す。実効光量の照会では人工日光を時刻・天候で減光しない。
- 自然光と人工日光を描画頂点に別々に保持する。自然光だけの領域には元の光マップを使い、両方が混ざる領域ではそれぞれの明るさを合成する。地形に時刻・天候の色を固定しない。
- 色の計算にはMinecraft標準の処理を再利用する。ガンマ、暗闇、暗視、通常のブロック光の揺らぎなどの処理も通る。地形の光マップ補間と、エンティティの直接参照の違いも維持する。
- 日照センサーは最終的な信号だけを一度書き込む。夜の値と人工の正午の値を順番に書き込み、意図しないレッドストーンのパルスを作る処理にはしない。
- 光の伝播結果をキャッシュし、変更時に再計算する。近傍チャンクの索引を使い、無関係な場所の変更で全パネルを走査しない。描画・光処理のワーカーは完成済みの結果だけを読み、サーバーのメインスレッドへのチャンク要求を発生させない。
- 未読込チャンクを照明のために読み込まない。登録は読込中のパネルのみとし、ワールドの終了時にも破棄する。キャッシュの値からLevelを強参照しない。
- 通信・保存用の自然光データへ人工日光を焼き込まない。両側で同期されたブロックから再計算し、消灯時の残光を防ぐ。旧版のブロック光15が残るセーブには、パネル読込時に光源の再評価も要求する。

## 検証

- 必須GameTest全490件。今回の追加8件は実際のSKY・実効光量、ガラス・水・不透明ブロック、面の形状、影への拡散、電源・撤去・再読込、32ブロックを超える高さ、通常・反転センサー、雨天の真夜中の日焼けと世界設定の保持を確認する。
- 既存のFE供給・消灯テストと、空のないディメンションの日照センサーも再検証する。非同期の標準光更新は、完了を待って確認する。
- 実クライアントで標準の晴天・正午と人工日光の光マップ全256組を比較する。雨天の真夜中でも同じ値になること、自然光用の領域は夜の色を保つことを確認する。
- 同じ床の84,000画素を比較し、正午の屋外と雨天の真夜中の点灯時がRGBで一致することを確認する。消灯時に暗くなり、再点灯時は同じ画素へ戻ることも確認する。
- 標準の地形描画、エンティティ描画、NeoForgeのSmoothQuadLighterも確認する。ビルド、翻訳、モデル、実績、説明文、支援者名簿、配布検証も実行する。

## 動作の範囲

ワールドの時刻・天候、ディメンションの性質は保持する。時計や睡眠など、ワールド時刻そのものを扱う処理は元の時刻に従う。検証対象はMinecraft 1.21.1 / NeoForgeの標準処理と上記の描画経路。独自の照明エンジン・シェーダーパックや、時刻だけで日照を判定する他MODとの組合せは未検証。

再実行手順:

```sh
./gradlew build runGameTestServer -PtestTickRate=200
python tools/review/prepare_rayleigh.py
./gradlew -I tools/review/rayleigh.gradle runClient
python tools/review/check_rayleigh_png.py build/rayleigh-review/screenshots
./gradlew build
python tools/check_release_1211.py --loader neoforge --build-dir build
```

最後の通常ビルドで検査専用コードを配布物から除き、配布検証で混入していないことを確認する。
