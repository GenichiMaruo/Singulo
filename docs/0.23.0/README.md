# 0.23.0

開発中のバージョン。

## 地表観測拠点の周りの地面をならす（singulo:graded）

地表観測拠点は jigsaw の型紙を `beard_thin` で地面に合わせて置くが、斜面では箱の上の地面を削りきれない。型紙で何も置かないマス（八角形の建物の四隅や、外壁の外の縁の上）には元の地面が残り、建物の欠けた所に土が盛られたように見えていた。

0.23.0 から、`worldgen/structure/observation_post.json` は jigsaw を `singulo:graded`（`ruin/GradedStructure`）で包む。置いたあと（`afterPlace`）に、各チャンクで次の高さより上にある自然の地面（`#minecraft:overworld_carver_replaceables` のうち液体でないもの）を取り除く。

- 型紙の箱の中と、箱のすぐ外の1列: 床（型紙のいちばん下の段）の1段下。
- その先: 箱からの水平距離（切り上げ）1マスごとに1段高い斜面。範囲は箱から12マスまで（地形の調整のある構造物が置かれるチャンクの範囲と同じ）。

型紙のブロック・水には触れない。取り除いた列の上に土が出たら、取り除いた中でいちばん上にあった表面のブロック（草ブロック・ポドゾルなど）に戻す。それより急な山では、12マス先に段差が残る。

すでに生成されたチャンクは変わらない。生成ファイルは `tools/gen_data.py` の `graded()` から作る。確認は `RuinGameTests.gradedRuinClearsGroundAroundBuilding`。

## 旧遺構の再構築

施設再構築装置は、銅ブロック・ダイヤモンド・精密アクチュエーター・クリスタルメモリでクラフトできる。旧版で生成され、通常ボスを倒して保管庫の封鎖が解けている施設の起動ブロックに使う。クリエイティブでは撃破前にも使えるが、戦闘中と警報中は対象外で、保管庫は封鎖されたままになる。地表観測拠点は対象外。最初に上書き範囲と警告を表示し、30秒以内に同じ装置で同じブロックをスニークしながら再クリックすると実行する。

実行前にワールドをバックアップし、建造物・収納・貴重品を退避する。範囲の地形、ブロック、建造物、収納は上書きされ、取り消せない。初期設定では、シングルプレイのワールド所有者とサーバー管理者だけが実行でき、対象範囲のチャンクがすべて読み込み済みで、ほかのプレイヤーが範囲内にいない必要がある。消費した場所は再利用できない。処理中断時の地形ロールバックはない。

旧施設の保管庫の中身と再生履歴は引き継ぐ。地下アンドロイド研究所では、保存されている部屋・通路・立坑の配置を基に現行の部品で置き直す。通常の4施設は起動ブロックの座標と元の向きを保ち、現行の施設を置く。旧施設の範囲が新施設より広い部分は取り除かない。

`config/singulo-server.toml` の `[facilityReconstruction]` で変更できる。変更後はワールドを開き直す（専用サーバーは再起動）。

```toml
[facilityReconstruction]
recipeEnabled = true
multiplayerAccess = "admins_only"
```

`recipeEnabled = false` は新規クラフトだけを禁止し、すでに入手した装置はこの設定では無効にならない。マルチプレイ（専用サーバーまたはLAN公開中）は `admins_only`（管理者のみ）、`everyone`（全員）、`disabled`（管理者も含め禁止）から選ぶ。LAN未公開のシングルプレイにはこの権限設定は適用されない。
