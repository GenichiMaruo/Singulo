# Singulo — 한국어 설명서

[README](../README.md) · [日本語](manual-ja.md) · [English](manual-en.md) · [简体中文](manual-zh-cn.md) · [繁體中文](manual-zh-tw.md) · [제작법 갤러리](recipes/README.md)

## 어떤 모드인가요?

Singulo는 작은 열전 발전기에서 시작해 회전하는 블랙홀 반응로까지 발전하는 산업 기술 모드입니다. 재료를 가공하고, 전력과 촉매를 공급하며, 멀티블록 장치를 건설해 다섯 기술 단계를 진행합니다.

탐험도 진행에 필요합니다. 경비가 있는 유적에서 직접 만들 수 없는 기록과 손상된 부품을 회수하고 복원하면 다음 기술을 개발할 수 있습니다. 후반에는 중력 제어, 보호막, 시간 가속, 원격 물류를 이용할 수 있습니다. 초전도, 입자 가속기, 카시미르 효과, 호킹 복사를 소재로 삼지만, 게임을 위해 조정된 수치와 기능이며 완전한 물리 시뮬레이션은 아닙니다.

## 설치

- **Minecraft 1.21.1**과 해당 버전용 **NeoForge 21.1.256 이상**이 필요합니다. 게임은 Java 21을 사용합니다.
- JAR 파일을 `mods/`에 넣습니다. 멀티플레이에서는 클라이언트와 서버 모두 설치해야 합니다.
- JEI는 선택 사항이며 기계 제작법과 멀티블록 건설 정보를 표시합니다.
- 에너지 케이블은 모드에 포함됩니다. 아이템과 유체 자동 운송에는 호환되는 운송 모드를 사용할 수 있습니다.

소스 빌드는 [README의 개발 안내](../README.md#開発するには)를 참고하세요.

## 처음 시작하기

1. **핸드북을 엽니다.** 첫 접속 시 Singulo 안내서을 받습니다. 우클릭하여 1단계와 진행 페이지를 읽으세요.
2. **강철과 세라믹을 만듭니다.** 철과 석탄으로 강철 혼합물을 제작하고 용광로에서 제련합니다. 점토, 네더 석영, 뼛가루, 모래로 굽지 않은 세라믹을 만들고 화로에서 굽습니다.
3. **회로와 프레임을 만듭니다.** 강철, 세라믹, 구리, 레드스톤이 초기 재료입니다. 정확한 수량은 [제작법 갤러리](recipes/README.md)를 확인하세요.
4. **발전하고 전력을 배분합니다.** 열전 발전기 옆에 지원되는 열원(불이 붙은 모닥불, 마그마 블록, 용암)과 냉원(물, 눈 블록, 얼음)을 배치하고 구리 전선으로 기계에 연결합니다.
5. **건설과 탐험을 함께 진행합니다.** 소성로, 압축기, 전해조, 기록 보관 단말기를 설치합니다. 탐험가의 나침반으로 관측소를 찾아 기록과 손상된 부품을 회수·복원하고 첫 냉각탑을 준비하세요.

온도 차가 커지면 발전량이 증가하지만 냉원의 허용 범위를 넘으면 물과 얼음이 소모되거나 상태가 변합니다. 발전기 화면을 확인하세요.

## 다섯 단계

| 단계 | 주요 목표 | 가능한 기술 |
| --- | --- | --- |
| 1: 시작 | 강철, 세라믹, 회로, 열전 발전 | 소성, 압축, 전기 분해, 기록 복사, 부품 수리 |
| 2: 극저온 | 냉각탑, 가속기 링, 뮤온 촉매 | 초전도체, 극저온 터빈, SMES 저장, 정밀 조립, 청크 로딩 |
| 3: 양자 | 연구동 회수품, 액체 헬륨 | 양자 부품, 레이저 냉각, 보스 응축 촉매, 탐험 도구, 관성 제어 |
| 4: 시간 | 배양 시설 회수품, 시간 결정 성장 | 축퇴 압축로, 카시미르 공동의 특이 물질, 축퇴 열로, 탐사 기지 |
| 5: 특이점 | 최종 실험 시설 수호자 격파, 특이점 씨앗 활성화 | 펜로즈 반응로, 특이점 코어, 보호막, 시간 가속, 중력 도구, 웜홀 물류 |

이 단계는 재료와 기술의 진행을 설명합니다. 발전 과제를 달성해도 제작법, 전력, 필요한 부품을 대신하지 않습니다.

## 전력, 물류, 촉매

에너지 단위는 FE입니다. 구리 전선에서 초전도 케이블, 위상 전선, 지평선 버스로 업그레이드할 수 있습니다. 구리는 전력을 손실하며 연결망 용량은 가장 약한 케이블에 제한됩니다. 지평선 버스에는 상한이 없어 Singulo 장치끼리는 1 tick에 약 21억 FE를 넘게 보낼 수 있습니다(다른 모드의 장치에는 한 대당 약 21억 FE/t까지). 실제로 전력이 흐르는 케이블만 흐름 방향으로 물결치듯 빛나며, 밝기는 흐르는 전력량에 따라 달라집니다.

일반 가공 기계는 면 설정 화면에서 입력, 출력, 자동 배출을 지정합니다. 전해조처럼 두 가지 기체를 내보내는 기계는 기체마다 출력 면을 따로 정할 수 있습니다. 화면 오른쪽의 전원 버튼으로 기계를 멈출 수 있고, 전력만으로 만들 수 있는 것이 있는 기계(냉각탑의 액체질소 등)에는 그 레시피를 건너뛰는 스위치도 있습니다. 멀티블록은 공용 입출력 포트를, 펜로즈 반응로는 전용 추출 포트를 사용합니다. 케이블은 에너지만 운송하며 아이템과 유체는 운송하지 않습니다.

촉매는 전용 슬롯에 넣는 소모품입니다. 뮤온 촉매, 보스 응축 촉매, 시간 결정 촉매, 특이점 코어 순으로 발전합니다. 같은 등급이면 정상 작동하며 한 등급 낮으면 속도는 절반, 마모는 두 배입니다. 두 등급 이상 낮으면 작동하지 않습니다. 높은 등급은 속도와 마모에 보너스를 줍니다. 소진된 촉매는 전력 요구량을 높이며 전력 부족도 마모나 제품 품질에 영향을 줄 수 있습니다. 사용한 촉매는 재활용 제작법이 있습니다.

시간 결정 성장은 기본 **24,000 작동 틱**, 20 TPS에서 약 20분입니다. 청크가 로드되지 않으면 진행하지 않습니다. 시간장과 서버 설정에 따라 실제 시간이 달라집니다.

## 멀티블록 건설

제어기를 놓고 **홀로그램 투영기로 우클릭**합니다. 투영과 부족한 재료 목록을 따라 청록색 위치를 채우고 빨간 장애물을 제거하세요. 웅크린 상태로 프로젝터를 사용하면 조절 가능한 구조의 크기를 바꿉니다. 완성 후에는 부품을 우클릭해도 제어기 화면이 열립니다.

| 기계 | 크기와 조건 |
| --- | --- |
| 극저온 냉각탑 | 5×5, 높이 7–15, 가운데가 좁아지는 구조. 액체 헬륨은 높이 10 이상 필요 |
| 입자 가속기 | 가로 정사각형 링, 변 길이 8–32. 모든 모서리와 둘레의 최소 1/4에 자석 배치. 제어기는 링 옆 |
| 축퇴 압축로 | 닫힌 5×5×5 프레스 |
| 카시미르 공동 | 5×5×5 용기, 내부 위아래 거울판이 마주보도록 배치 |
| 축퇴 열로 | 5×5×7, Lv2 압축 블록과 시간 결정 촉매 사용 |
| 펜로즈 반응로 | 13×13×13 안의 서로 직교하는 세 링, 반지름 6. 제어기는 중심보다 5블록 아래 |
| 사건 지평선 보호막 탑 | 5×5, 높이 9 |
| 티플러 원통 | 5×5×9. 시간장이 지원되는 기계의 가공을 가속 |
| 웜홀 생성기 | 5×5×5 안의 구형 구조 |

외형 크기뿐 아니라 프레임, 창, 내부 부품, 필요한 빈 공간도 일치해야 합니다. 공용 포트는 지정된 패널을 대체합니다. 가속기 포트는 제어기 양옆에 놓습니다. 반응로 추출 포트는 링 외벽을 대체하며, 여섯 교차점에는 자이로 드라이브, 열두 대각선 위치에는 **노심 안정화 코일**을 사용합니다.

## 유적 탐험

| 유적 | 회수품과 용도 |
| --- | --- |
| 관측소 | 관측 기록, 열화된 제어 장치. 초전도와 뮤온 기술의 시작 |
| 연구동 | 양자 데이터 조각, 열화된 냉각 원자 트랩. 양자 기술에 사용 |
| 배양 시설 | 배양 데이터, 열화된 시간 결정 씨앗. 시간 기술과 특이 물질에 사용 |
| 최종 실험 시설 | 이상 표본, 첫 휴면 특이점 씨앗. 지평선 감시자가 경비 |

지상에 있는 유적은 관측소뿐이며, 연구동은 얕은 지하, 배양 시설은 깊은 지하, 최종 실험 시설은 가장 깊은 지하에 묻혀 있습니다. 탐험가의 나침반은 처음에는 관측소만 찾을 수 있습니다. 공략한(직접 보관함을 연) 유적의 보관함을 웅크린 채 우클릭하면 조정되어 다음 유적도 찾을 수 있습니다. 공중에서 웅크린 채 우클릭하면 찾을 유적을 바꿉니다. 관리자는 `/singulo ruin <유적> [위치]`로 유적을 바로 세울 수 있습니다. 중력파 탐지기와 중성미자 스캐너도 탐험을 돕습니다. 비운 보관함은 기본적으로 관측소·연구동은 게임 시간 7일 후, 배양 시설·최종 실험 시설는 14일 후 다시 채워집니다.

각 유적에는 다음 단계의 열쇠로만 열리는 **봉인 컨테이너**가 있습니다(자기 잠금, 양자 잠금, 시간 잠금, 마지막으로 특이점 잠금). 열쇠는 정밀 조립기에서 만들며 쓸 때마다 소모됩니다. 안에는 재료와 색이 있는 조명, 때로는 다른 곳에서 구할 수 없는 도구(오버클럭 칩, 중력 부츠, 촉매 안정제, 차원 주머니)가 들어 있습니다. 봉인된 컨테이너를 억지로 부수면 내용물까지 사라집니다. 해당 단계에 이르면 직접 만들 수도 있으며, 웅크린 채 열쇠를 쓰면 봉인합니다.

탐사 기지는 플레이어가 보관함을 열어 발견한 유적에만 방문합니다. 기본 설정에서는 4단계 기지가 관측소 회수를 자동화합니다. 배양 시설과 최종 실험 시설는 항상 직접 탐험해야 합니다. 기록 보관 단말기에서 기록 조각을 해독하고 해독된 아이템을 읽으면 고대 이야기가 핸드북에 추가됩니다.

## 블랙홀과 후반 기술

첫 특이점 씨앗을 노심 제어기에 넣고 점화를 시작합니다. 기본 설정에서 **10초 안에 50 GFE**를 공급해야 합니다. 이후 형성 과정으로 코어가 만들어집니다. 먼저 대용량 전력망을 준비하세요.

작동 중에는 질량 펠릿을 공급하고 코어 질량과 스핀을 관리합니다. 스핀은 강착 효율을, 질량은 연료 주입 한도를 결정합니다. 수집기는 각각의 작동 조건에 따라 제트 응축물, H 응축물(호킹 응축물), 특이 물질을 생성합니다. 펠릿을 통한 성장은 제한되지만 다른 물질을 안전 범위 이상 공급하면 반응로가 붕괴하고 통제되지 않는 블랙홀이 남을 수 있습니다.

후반 장치는 기지를 보호하고 지원되는 기계를 가속하며 청크를 로드하고 중력을 조작합니다. 계량 구동기는 인벤토리에서 작동하며 Curios 장비 슬롯이 필요하지 않습니다. 웜홀 입구를 한 쌍으로 생성·안정화·배치하면 주변 포트가 먼 곳의 전력, 아이템, 유체를 연결합니다. 특이 물질로 입구를 유지하고 목적지 청크도 로드해야 합니다.

## 문제 해결과 위험

- **기계가 멈춤:** 전력, 재료, 촉매 등급과 남은 수명, 출력 공간, 유체를 확인하세요. 멀티블록은 구조와 포트 위치도 확인합니다.
- **도구 조작:** 관성 제어 건틀릿은 우클릭을 누르고, 중력자 조작기는 좌클릭을 누릅니다. 대상을 띄운 상태에서 우클릭으로 충전한 뒤 놓으면 던집니다. 게임 내 키 설정도 확인하세요.
- **떠나면 공장 정지:** 로드되지 않은 청크는 가공하지 않습니다. 세계선 앵커도 작동 조건을 유지해야 합니다.
- **위험:** 블랙홀은 물체를 끌어당기고 조석 피해를 주며 사건 지평선에서 개체를 삼킵니다. 수소 누출은 불 근처에서 폭발할 수 있습니다. 큰 가속기의 저장 에너지가 부족하면 스트레인지렛이 누출될 수 있으므로 자기 병과 보호 장비를 준비하세요.

기본 텍스처는 16×16이며 내장 **Singulo HD** 리소스 팩으로 32×32를 사용할 수 있습니다. 가속기의 변과 모서리는 자동 연결되고 작동 중에는 빛이 둘레를 순환합니다.

이 설명서는 현재 구현과 기본 설정을 기준으로 합니다. [제작법 갤러리](recipes/README.md)와 [문서 검증 기록](documentation-audit.md)을 참고하세요. 서버 설정과 데이터 팩이 제작법이나 동작을 바꿀 수 있으므로 해당 세계의 게임 내 정보를 확인하세요.
