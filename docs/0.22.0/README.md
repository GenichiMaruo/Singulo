# 0.22.0: 刀型アンドロイド「ルージュ」

研究棟の封印核に「覚醒の残響核」を使い、覚醒した残響の番人を倒すと、25%の確率で「小型クリスタルメモリ（刀型）」が手に入る。抽選は参加人数にかかわらず撃破ごとに1回。当たると、消えかけた番人の残像を紅い一閃が横切り、胸の記録結晶が砕けた位置にメモリが1個残る。アンドロイド組立ステーションにこのメモリを入れてルージュを印刷する。

## 位置づけ（AndroidKind.KATANA）

- `Origin.HIDDEN`・印刷の電力3倍。自然生成の遺構印刷台と地下アンドロイド研究所の試作機の対象からは除外される。
- `katana_android_spawn_egg` と `android_memory_katana` は `SinguloItems.HIDDEN`（クリエイティブタブ・JEI に出さない）。メモリの名前は紫（`EPIC`）。
- 強み: バックパック内蔵（`builtInPack`。背負い物の模型は出さない）、内蔵バッテリー1個（充電の満タン1.5倍）、作業1.5倍速。体力34・装甲6・ノックバック耐性0.4。射撃型の「護衛範囲2倍」の代わりに、近接向けの頑丈さを持つ。

## 見た目

- 黒髪に紅のインナーカラー、紅の光（`ACCENT = 0xFF3A54`）。配色は `tools/androids.py` の `katana_android`。
- 刀は2本。
  - **腰の刀**（ふだん使いの打刀）: 左の腰に、鯉口を前上がり・刃を上にして差す。黒漆の鞘に銀の金具。刀身は素の鋼に、白く冴えた刃文（光らない）。抜いている間は右手に持つ（模型の `katana_grip`）。
  - **背中の紅い刀**（紅一閃の刀）: 左肩の上（鯉口）から右の腰（鐺）へ斜めに背負う。朱の漆の鞘に金の金具、背の側に紅の光の線。刀身は少し長く、暗い鋼に紅く光る刃文。紅一閃では左手（`katana_grip_l`）に抜き、とどめを刺したときはそのまま刀礼に使う。
- 腰の打刀は、右手で柄を握って鞘引きし、抜ききってから右へ払う（`STATE_DRAW`）。戦闘や刀礼が終わり、敵のいないまま2.5秒たつと、切っ先を鯉口に合わせて刀を差し戻す（`STATE_SHEATHE`）。納刀中に次の敵が現れた場合も、鍔が着いてから抜き直す。作業・充電では腰の鞘に戻す。
- 背中の左下には、真鍮の留め具を付けた黒漆の手入れ箱を横向きに留める。臙脂の縁取りがある生成りの布が蓋からのぞく。バックパックを装備すると箱はその外側に付く。
- 設計メモリはアニメーションつき（`katana_memory`）: 紅の斬線が結晶を走り抜け、結晶が明るんでから鎮まり、火の粉のような粒が立ちのぼる。表示灯は鼓動のように2回ずつ明滅する。シエルの「光が流れ続ける」とは別の動き。

## 技

| 状態 | 内容 |
|---|---|
| `STATE_CUT` → `STATE_RETURN_CUT` | 3.1ブロック以内で袈裟斬り（6）。6割で返し斬り（5）が続き、どちらも斬撃の半径は3.3ブロック |
| `STATE_STEP` | 3.5〜10ブロックから踏み込み斬り（7）。始動時の敵の位置から約2ブロック手前まで踏み込んで振り抜く |
| `STATE_IAI_STANCE` → `FLASH` → `ZANSHIN` | 14ブロック以内の敵に、二刀で「紅一閃」を放つ |
| `STATE_VICTORY` | 通常の斬撃で勝ったとき、背中の紅刀を半分だけ抜いて一礼 |
| `STATE_IAI_VICTORY` | 紅一閃で勝ったとき、抜いたままの紅刀を掲げてから背中に納刀 |

### 紅一閃（特殊モーションの大技・二刀）

1. 構え（34 tick）: 右手の打刀を低く右後ろへ流し、左手で左肩の紅刀を握って腰を落とす。朱鞘の光が鐺から金具をたどって柄頭に集まる。最後の8 tick で向きを固め、わずかに刃をのぞかせる。
2. 駆け抜け（6 tick）: 紅い刀を抜きざまに、右の刀は横一文字・左の刀は左上から右下へ、二刀を交差させて相手を突き抜ける。相手の2.2ブロック先を目指して最大16ブロック走り、壁の手前で止まる。通り道の相手をまとめて浅く斬り（4）、覚えておく。
3. 残心では血振りで紅刀を体の横へ開く。刀身を見せたまま24 tick目に深い斬撃（16）が走る。戦闘が続く場合は切っ先を背中の鯉口へ導き、33 tick目に納刀、36 tickで構えに戻る。最後の相手を倒した場合は、ここから直接、紅刀を掲げる刀礼に入る。

近接の間合いで大技の準備ができると、3ブロック以上離れるまで下がる（3秒下がれなければ斬り合いに戻る）。駆け抜けの途中で相手を倒した場合も、残心で通り道の斬撃を解決してから刀礼に入る。

### 戦闘後の刀礼

- 通常攻撃で最後の相手を倒すと、右の打刀を脇に下げ、左肩の紅刀を半分だけ抜いて一礼する。刃文にひと筋の光が走り、鍔が鞘に着いてから手を離す。礼は40 tick（2秒）。
- 紅一閃で決めると、血振りで横へ開いた紅刀をそのまま左手で掲げ、刀身全体を見せる。礼の後で切っ先を背中の鯉口に合わせ、39 tick目に鍔を鳴らし、46 tick（2.3秒）で構えに戻る。
- 近くに戦う相手が残っていれば攻撃を続ける。刀礼の途中で再び接敵すれば、左手で紅刀を納めながら右の打刀で戦闘に戻る。

### 待機中の刀の手入れ

敵が近くにおらず、作業もせず地上で立ち止まっていると、ときどき打刀を手入れする（`STATE_MAINTENANCE`、96 tick＝4.8秒）。左手で背中の箱から布を取り、右手に抜いた打刀の刀身を二度拭く。打刀を腰に納め、布を元の箱へ戻すと蓋が閉まる。移動や接敵で中断し、すでに抜き切った打刀はそのまま戦闘に使う。

### 大技中の体の発光（シエルとの違い）

シエルはレールガンを溜める間「髪の筋と毛先」が光る。ルージュは**体の継ぎ目に回路のような紅の光の筋が浮き出る**。

- 光の筋は3段のテクスチャ（`katana_android_surge_{0,1,2}.png`、`tools/androids.py` の `KATANA_SURGE`）。胸・胴・腰 → 腕・腿・スカート → 前腕・籠手・すね・センサーの羽の順に、構えの溜めに合わせて段ごとに浮き出て、心臓の鼓動のように脈打つ。
- 残心から構えへ戻るにつれ、光は外側の段から引いていく。
- 同時に、髪とスカートが下から吹き上がるように浮き、左肩の上の紅い刀の柄頭に光が集まり、足元に紅の輪と立ちのぼる光の粒。向きを固めると輪が締まる。
- 駆け抜けで二刀が交差すると、紅刀の棟に沿って短い残光が伸びる。通り道には上下から交わる細い斬線と残像が残る。残心では刀を見せる間に斬線が薄れ、遅れて入る斬撃に合わせてもう一度閃く。

## 検査

`RougeMemoryGameTests` では、覚醒した本体の撃破でだけ抽選すること、25%の境界、人数によらず一閃の後に記録結晶の位置へ1個現れることを検証する。演出の途中や出現直後の再読み込み、組立ステーションがメモリを刀型と認識することも確認する。

`src/gameTest/java/.../android/KatanaGameTests.java`:

- 隠し型であること（一覧に出さない・紫・印刷倍率が射撃型と同じ）
- 内蔵バックパック・充電1.5倍・作業1.5倍速・印刷3倍
- 紅一閃の通り道の上の相手だけを斬り、残心で深い斬撃が入る。同じ相手に遅延斬撃を二度当てない
- 通常歩行を止めた状態で、3ブロック先の敵に袈裟斬り、10ブロック先の敵に踏み込み斬りが当たる。踏み込み先の壁の裏にいる敵は巻き込まない。
- 13.9ブロック先の敵に紅一閃を構え、16ブロックを駆け抜けて残心の遅延斬撃まで当てる。
- 通り道が壁の手前で止まる
- 敵がいなくなると納刀する。抜刀中に敵が消えた場合と、納刀中に次の敵が現れた場合も、腰の刀を最後まで受け渡す。
- AI つきで、抜刀から紅一閃（構え・駆け抜け・残心）まで進む。駆け抜けでは二刀を持ち、紅一閃のあとも腰の刀は抜いたまま
- 待機から自発的に手入れを始め、持ち物や電力を消費せずに片づける。移動で中断し、接敵した場合は手にある打刀で次の攻撃を当てる。
- 通常の斬撃と紅一閃で最後の相手を倒し、それぞれの刀礼に入ることを確認する。紅一閃の勝利では残心から礼まで紅刀を抜いたままつなぎ、最後に一度だけ納める。途中で次の相手が来た場合も戦闘に復帰できる。

武器のクライアント検査（`tools/review/android-weapon.gradle`）では、両刀が手と鞘の間を移る直前・直後に、柄の位置と刃の向きが揃うことをバックパックあり・なしで検証する。紅一閃は勝敗の通知を12 tick遅らせても紅刀が抜いたまま待つこと、刀礼や再接敵に切り替わる瞬間に切っ先の位置がつながることも確かめる。
手入れでは、左手と箱の間で布を受け渡す瞬間に位置と向きが一致することと、二度拭く間に布が刀身に沿って動くことを、同じ二つの装備条件で確かめる。
