# Singulo 0.12.0 — Minecraft 1.20.1

公開タグ `v0.12.0` を Forge 47.4.26 / NeoForge 47.1.106、Java 17 の共通ブランチへ移植。

- 共通フレームGUI・ポップアップ・クリック音・装置の表情・上位作業台を反映。
- 水中・無重力の移動、充電・回復、素材代替と相対面指定を維持。
- 1.20.1の描画・スロット座標・NBT・経路探索APIに適合。Embeddium 0.3.31 / Distant Horizons 3.3.3 の任意連携を維持。
- 公開元357レシピを1.20.1形式へ正規化し、費用・数量・時間・電力を独立照合。
- 必須GameTest 541件、Mekanism連携各2件、5言語の実GUI 212画面、描画比較・5回の再入場を両ローダーのCIで確認する。

成功した同一ソースのCIから配布JARを昇格し、`v0.12.0-1.20.1F` / `v0.12.0-1.20.1N` のタグでCurseForgeへ公開する。GitHub ReleasesにJARは添付しない。
