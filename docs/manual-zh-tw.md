## 這是什麼模組？

Singulo 是一個工業科技模組：從小型熱電發電機起步，逐步建設能夠執行旋轉黑洞反應堆的工廠。加工材料、供給電力和催化劑、搭建多方塊裝置，是五個科技階段的核心玩法。

探索也是進度的一部分。有守衛的遺蹟提供無法直接製造的記錄和損壞部件；回收並修復它們，才能開啟後續科技。後期還有引力控制、護盾、時間加速和遠端物流。超導、粒子加速器、卡西米爾效應與霍金輻射是題材；機制和數值為遊戲而設計，並非完整的物理模擬。

## 安裝要求

- Minecraft **1.21.1**，以及對應版本的 **NeoForge 21.1.256 或更高版本**。遊戲使用 Java 21。
- 將 JAR 放入 `mods/`。多人遊戲的客戶端和伺服器都需要安裝。
- JEI 為可選依賴，提供機器配方和多方塊建造資訊。
- 模組自帶能量線纜；物品和流體的自動運輸可使用相容的運輸模組。

從原始碼構建請參閱 [README 的開發說明](../README.md#開発するには)。

## 第一次遊玩

1. **開啟手冊。** 首次進入世界會獲得 Singulo 手冊。右鍵開啟，閱讀階段 1 和進度頁面。
2. **製作鋼和陶瓷。** 鐵與煤合成鋼混合料，再用高爐燒煉。黏土、下界石英、骨粉和沙合成未燒製陶瓷，再用熔爐燒製。
3. **製作電路與框架。** 鋼、陶瓷、銅和紅石是初期材料基礎。準確用量見[配方圖集](recipes/README.md)。
4. **發電並配電。** 熱電發電機旁放置支援的熱源（點燃的營火、岩漿塊或熔岩）和冷源（水、雪塊或冰），用銅線連線機器。
5. **同時建設與探索。** 建立窯爐、壓縮機、電解機和檔案終端。用探索羅盤尋找觀測站，帶回記錄與損壞部件並修復，準備建造第一座冷卻塔。

溫差越大，發電量通常越高；超出冷源耐受範圍會消耗或降低水與冰的狀態。請檢視發電機介面，不要認為冷源永遠不會變化。

## 五個科技階段

| 階段 | 主要目標 | 解鎖的能力 |
| --- | --- | --- |
| 1：啟動 | 鋼、陶瓷、電路、熱電發電 | 燒製、壓縮、電解、複製記錄與修復部件 |
| 2：低溫 | 冷卻塔、加速器環、繆子催化劑 | 超導材料、低溫渦輪、SMES 儲能、精密裝配與區塊載入 |
| 3：量子 | 研究樓回收物與液氦 | 量子部件、鐳射冷卻、玻色凝聚態催化劑、探索工具與慣性控制 |
| 4：時間 | 培養設施回收物與時間晶體生長 | 簡併壓縮爐、卡西米爾腔產生的奇異物質、簡併熔爐與探測站 |
| 5：奇點 | 擊敗最終實驗室守衛，喚醒奇點種子 | 彭羅斯反應堆、奇點核心、護盾、時間加速、引力工具與蟲洞物流 |

階段描述材料和科技的推進。獲得進度成就不會代替配方、電力和必要部件。

## 電力、物流與催化劑

能量單位為 FE。工廠發展後，可從銅線升級為超導線纜、拓撲導線和視界匯流排。銅線有能量損耗，網路容量受最弱線纜限制。

普通加工機器的側面設定可指定各面的輸入、輸出和自動輸出。多方塊裝置使用通用多方塊輸入輸出埠，彭羅斯反應堆使用專用提取埠。線纜僅運輸能量，不運輸物品或流體。

催化劑是放在專用槽中的消耗品，依次為繆子催化劑、玻色凝聚態催化劑、時間晶體催化劑和奇點核心。同級正常執行；低一級速度減半、磨損加倍；低兩級以上不能執行。高階催化劑可提高速度並降低磨損。耗盡的催化劑增加電力需求，供電不足也可能影響磨損或產品質量。用過的催化劑可以透過配方回收。

時間晶體預設需要 **24,000 個執行刻**，在 20 TPS 時約為 20 分鐘。區塊未載入時不生長；時間場和伺服器配置可改變實際用時。

## 多方塊建造

放置控制器後，**手持全息投影儀右鍵控制器**。按投影與缺少材料列表建造：填充青色位置，移除紅色阻擋。潛行使用投影儀可切換可調結構的尺寸。組裝成功後，右鍵部件也能開啟控制器介面。

| 裝置 | 尺寸與主要條件 |
| --- | --- |
| 低溫冷卻塔 | 5×5，高 7–15 格，中間收窄；生產液氦需要至少高 10 格 |
| 粒子加速器 | 水平正方形環，邊長 8–32；四角及至少四分之一週長使用磁體，控制器放在環旁 |
| 簡併壓縮爐 | 封閉的 5×5×5 壓機 |
| 卡西米爾腔 | 5×5×5 容器，內部頂部與底部的鏡面板相對 |
| 簡併熔爐 | 5×5×7，使用 Lv2 壓縮塊和時間晶體催化劑 |
| 彭羅斯反應堆 | 13×13×13 範圍內的三個正交環，半徑 6；控制器位於中心下方 5 格 |
| 事件視界護盾塔 | 5×5，高 9 格 |
| 蒂普勒圓柱 | 5×5×9；時間場加速受支援機器的加工 |
| 蟲洞發生器 | 5×5×5 範圍內的球形結構 |

外部尺寸只是起點，框架、窗戶、內部部件和必要空氣位置也必須符合要求。通用埠只能替換指定面板；加速器埠位於控制器兩側。反應堆提取埠替換環殼，六個環交點使用陀螺驅動器，十二個對角位置使用**反應堆穩定線圈**。

## 遺蹟探索

| 遺蹟 | 關鍵回收物與用途 |
| --- | --- |
| 觀測站 | 觀測日誌、劣化控制單元；超導和繆子科技的入口 |
| 研究樓 | 量子資料碎片、劣化冷原子阱；用於量子科技 |
| 培養設施 | 培養資料、劣化時間晶體種子；用於時間科技和奇異物質 |
| 最終實驗室 | 異常樣本、初始休眠奇點種子；由視界守衛看守 |

探索羅盤可切換遺蹟種類，引力波探測器與中微子掃描器提供進一步幫助。預設情況下，取空的觀測站和研究樓儲藏物在 7 個遊戲日後補充，培養設施與最終實驗室在 14 個遊戲日後補充。

探測站只會訪問玩家已經開啟儲藏物並發現的遺蹟。預設階段 4 的探測站可自動回收觀測站；培養設施和最終實驗室始終需要親自探索。在檔案終端解碼記錄碎片，再閱讀解碼物品，即可將古代故事加入手冊。

## 黑洞與後期科技

將第一顆奇點種子放入核心控制器，開始點火；預設要求在 **10 秒內供應 50 GFE**。隨後形成核心。點火前請準備大容量電網。

執行期間供給質量顆粒，管理核心質量與自旋。自旋決定吸積效率，質量影響燃料注入上限。收集器在各自的執行條件下產生噴流凝結物、H 凝結物（霍金凝結物）和奇異物質。顆粒帶來的質量增長有上限；供給其他物質超過安全範圍可能使反應堆坍塌並留下失控黑洞。

後期裝置可以保護基地、加速受支援機器、保持區塊載入並操縱引力。度規驅動器在物品欄中即可工作，不需要 Curios 裝備槽。蟲洞入口需成對生成、穩定並放置，附近埠連線遠處的能量、物品和流體。奇異物質維持入口，目標區塊必須保持載入。

## 故障排查與危險

- **機器不執行：** 檢查電力、材料、催化劑等級及剩餘壽命、輸出空間和流體。多方塊還需檢查結構與埠位置。
- **工具操作不同：** 慣性控制手套使用按住右鍵；引力子操縱器使用按住左鍵，懸浮目標時按住右鍵蓄力，鬆開投擲。檢查遊戲內按鍵設定。
- **離開後工廠停機：** 未載入區塊不會加工；世界線錨也必須持續滿足執行條件。
- **危險裝置：** 黑洞產生引力和潮汐傷害，並在事件視界吞噬實體。氫氣洩漏遇火可能爆炸。大型加速器儲能不足時可能洩漏奇異子，請準備磁瓶與防護裝備。

預設紋理為 16×16，可啟用內建 **Singulo HD** 資源包獲得 32×32 紋理。加速器邊與角自動連線，執行時有環繞的光效。
