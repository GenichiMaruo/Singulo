# Singulo — 日本語説明書

[README](../README.md) · [日本語](manual-ja.md) · [English](manual-en.md) · [简体中文](manual-zh-cn.md) · [繁體中文](manual-zh-tw.md) · [한국어](manual-ko-kr.md) · [Recipes](recipes/README.md)

## どんなmod？

Singuloは、**小さな発電設備から、ブラックホールを中心とする工場まで育てる工業mod**です。素材を加工し、電力と触媒を用意し、大型の装置を組み立てて、新しい技術へ進みます。

工場だけで完結しないのが特徴です。旧文明の遺構には、作れない記録や部品が眠っています。それらを持ち帰って復元することが、次の技術への足掛かりになります。終盤にはブラックホール発電に加えて、重力操作、シールド、時間加速、遠隔輸送を使えます。最後の目標は、ブラックホールの電力で宇宙そのものを生み出す「創世炉」です。

超伝導、粒子加速器、カシミール効果、ホーキング放射などが題材ですが、数値や挙動はゲーム用に調整されています。

## 必要な環境と導入

- Minecraft **1.21.1**、NeoForge **21.1.256以上の1.21.1対応版**。Minecraftの実行にはJava 21を使用します。
- SinguloのJARを `mods/` に入れます。マルチプレイではクライアントとサーバーの両方に導入します。
- JEIは任意です。導入すると装置のレシピやマルチブロックの組み方をゲーム内で調べられます。
- Singuloには電力用のケーブルがあります。アイテム・液体を配管で輸送したい場合は、対応する他modの輸送設備も使えます。

ソースからビルドする場合は [READMEの開発手順](../README.md#開発するには)を参照してください。

## 最初は何をすればいい？

1. **ハンドブックを開く。** 初回ログインで受け取る本を右クリックします。「段階1」と「進み具合」を見れば、序盤の目標が分かります。
2. **鋼鉄とセラミックを作る。** 鉄と石炭から鋼の素を作り、溶鉱炉で鋼鉄にします。粘土・ネザー水晶・骨粉・砂で未焼成セラミックを作り、かまどで焼きます。ネザーへ行く前なら、ネザー水晶の代わりに火打石2個でも作れます。
3. **回路とフレームを作る。** 鋼鉄、セラミック、銅、レッドストーンが序盤の基礎素材です。正確な材料数は [レシピ一覧](recipes/README.md)で確認できます。
4. **熱電発電機から電力を送る。** 発電機に、燃えている焚き火・マグマブロック・溶岩などの高温源と、水・雪ブロック・氷系の低温源を隣接させます。銅導線で装置へつなぎます。
5. **加工と探索を並行する。** 焼成炉・圧縮機・電解槽・アーカイブ端末をそろえ、探索コンパスで地表観測拠点を探します。持ち帰った記録や劣化部品を端末で書き写し・修復し、冷却塔の建造へ進みます。

温度差が大きいほど発電量は増えますが、低温源の許容差を超えると水や氷が劣化・消費されます。発電機の画面で状態を確認しましょう。マグマブロック＋青氷（約76 FE/t）や焚き火＋氷塊（約55 FE/t）は劣化しない安定した組み合わせです。溶岩＋青氷は約106 FE/tですが、青氷が約40秒で溶け始めます。最初は2〜4台で装置を交互に動かし、冷却塔に向けて増やしていけば十分です。

冷却塔の熱交換コアと冷却帯は、青氷の代わりに氷塊3個でも作れます。

## 5段階の進み方

| 段階 | 取り組むこと | できるようになること |
| --- | --- | --- |
| 1：起動 | 鋼鉄・セラミック・回路を作り、温度差で発電する | 焼成、圧縮、電解、記録の書き写しと部品修復 |
| 2：極低温 | 冷却塔と加速器を建造し、ミュオン触媒を作る | ミュオン触媒核融合炉、超伝導部品、極低温タービン、SMES蓄電、精密組立、チャンク保持 |
| 3：量子 | 研究棟の回収物と液体ヘリウムを使う | 量子部品、レーザー冷却、BE凝縮触媒、探索支援、慣性制御 |
| 4：時間 | ニホニウム筐体を作り、封鎖培養施設で回収した素材から時間結晶を育てる | 縮退圧縮炉、C空洞のエキゾチック物質、縮退熱炉、自動探査機 |
| 5：特異点 | 最終実験施設の守護機を倒し、特異点の種を目覚めさせる | Pリアクター、シンギュラリティ・コア、シールド、時間加速、重力操作、ワームホール |

段階5のあとは、覚醒したボスとの再戦や隠しボス、そして最終目標の創世炉が待っています。

段階は技術と材料の流れを示します。単に進捗を解除するだけで、必要な素材や電力が省略されるわけではありません。

## 電力・輸送・触媒

電力はFEです。銅導線から超伝導ケーブル、トポロジカル導線、ホライズン・バスへ設備を更新していきます。銅導線には損失があり、送電経路で容量が最も小さいケーブルが上限になります。別の分岐は影響しませんが、同じケーブルを通る送電は1 tickの容量を共有します。ホライズン・バスには上限がなく、Singuloの装置どうしなら1 tickに約21億FEを超えて送れます（ほかのmodの装置へは1台あたり約21億FE/tまで）。電力が実際に流れているケーブルだけが、流れの向きに波打つように光ります。明るさは流れている量で変わります。

受電する装置からケーブル経由で近い電源を先に使い、不足分を遠い電源で補います。同じ距離なら座標順です。近い電源が空の場合や、途中のケーブルの容量が足りない場合も、残りを別の電源が補います。ケーブルを切断すると、その配線の発光はすぐに消えます。

通常の加工装置は、画面の「面」から各面の入力・出力と自動排出を設定できます。電解槽のように2種類の気体を出す装置は、気体ごとに出す面を決められます。画面右の電源ボタンで装置を止められます。電力だけで作れるもの（冷却塔の液体窒素など）がある装置には、それを作るかどうかのスイッチもあります。マルチブロックは共通の搬入出ポート、Pリアクターは専用の抽出ポートを使います。Singuloのケーブルが運ぶのは電力で、アイテム・液体用のパイプではありません。

触媒は専用スロットに入れる消耗品です。ミュオン、BE凝縮、時間結晶、シンギュラリティ・コアの順に上位になります。同じティアなら標準運転、1つ下なら速度半分・消費2倍（量子熱機関・縮退熱炉は出力が定格の25%）、2つ以上下では起動できません。上位触媒には速度と消耗のボーナスがあります。残量が減ると必要電力が増え、電力不足は触媒の消耗や製品の品質にも影響します。この決まりは触媒スロットで「運転」する装置のものです。加工レシピに材料として書かれた触媒は、決まった個数か寿命を使うだけで、加工の速さは変わりません。

核融合炉・量子熱機関・縮退熱炉と、蓄電用の極低温タービンは、蓄電がほぼいっぱいになると待機して資源の消費を止め、75%未満で再開します。

時間結晶の育成は、既定で14,400稼働tick（20 TPSなら12分）です。未ロードの間は進まず、時間加速・時間膨張や設定によって所要時間が変わります。要求電力の80%以上なら純度は落ちず、それを下回った時間の割合だけ寿命が短くなります。使い切った触媒にはリサイクルレシピがあります。

炉心制御装置・特異点封入台・シールド発生塔コア・ワームホール生成器コアなどの設備には、精密組立台で作る**時間結晶モジュール**を使います。触媒スロットの時間結晶から新品の寿命の2/3（既定では30分）を切り出す部品で、重ねて持てます。残った寿命（既定15分）の触媒はそのまま運転に使えます。残りが新品の寿命の2/3に満たない触媒からは作れません。寿命の設定を変えると、切り出す量も比例して変わります。

### 0.10.0の電力と素材

- ミュオン触媒核融合炉が段階2の電源です。既定で4 kFE/t、水3000 mBと新品のミュオン触媒1個で10分動きます。触媒は2倍速で消耗するため、使いかけなら残寿命の半分の時間だけ動きます。
- 極低温タービンは発電用燃料を作る装置ではなく、液体窒素の蓄電から電力を回収する装置です。窒素1 mBの製造は250 FE、溶岩の横で最大90%を回収し、最大4.5 kFE/tを出します。高さ7の塔の窒素製造は約1786 FE/tで、給電不足でも進捗は保持されます。ほかの冷却塔加工は高い塔ほど総電力が少なくなります。
- 液体キャニスターは液体・ガスを1000 mB運べます。空の冷媒カートリッジは窒素100 mBを運び、注ぐと空容器が戻ります。精密組立の材料にした場合は容器ごと消費されます。
- 凝灰岩から亜鉛、粗銅の精錬副産物からビスマスを作り、一辺16以上の加速器でニホニウムを合成します。板と筐体は段階4〜5の装置や部品に使います。隕鉄は収束磁石に加え、磁気シールド・磁気瓶・ジャイロ駆動部にも使います。
- 骨粉は石灰粉、石炭は炭素粉で代替できます。未焼成セラミックの石英は火打石2個でも代替でき、亜鉛の蛍光体からグロウストーンダストも作れます。焼成炉では酸素250 mB・鉄2・石炭または炭素粉1から鋼鉄2を作れます。ペルチェ冷却器は水1000 mBを氷1個にします。
- 水素燃料電池は電解槽の逆で、電力を増やす装置ではありません。水素2 mBと酸素1 mBの割合で消費し、既定で水素1 mBあたり4.8 FE、最大240 FE/tを回収します。
- 時間結晶育成だけは低電力でも進み、純度・寿命が低下します。石炭・苔むした丸石・酸化銅の時間加工は要求電力を満たす必要があります。


## マルチブロックを組む

まずコントローラを置き、**ホロ投影機で右クリック**します。投影された形と不足する部品を確認し、水色の場所を埋め、赤い場所の障害物を除きます。スニークして投影機を使うと、可変サイズの装置の大きさを切り替えられます。完成後は部品の右クリックからも画面を開けます。

| 装置 | 外形・重要な条件 |
| --- | --- |
| 極低温冷却塔 | 5×5、高さ7〜15のくびれた塔。高さ10以上で液体ヘリウムに対応 |
| 粒子加速器 | 水平な正方形リング、一辺8〜32。四隅は収束磁石、磁石は周長の1/4以上。コントローラを隣接させる |
| 縮退圧縮炉 | 5×5×5の閉じたプレス |
| C空洞 | 5×5×5の容器。天面・底面の内側に鏡面プレート |
| 縮退熱炉 | 5×5×7の炉。圧縮ブロックLv2と時間結晶触媒で5 MFE/t（BE凝縮触媒なら1.25 MFE/t） |
| Pリアクター | 13×13×13に収まる3本の直交リング。半径6、中心の5ブロック下にコントローラ |
| シールド発生塔 | 5×5、高さ9 |
| Tシリンダー | 5×5×9。対応する装置の処理を時間の場で加速 |
| ワームホール生成器 | 5×5×5の球状装置 |

外形だけでは完成しません。枠、窓、内部の部品や空気の位置も投影に合わせます。共通ポートを置けるのは外装板など指定された位置だけです。加速器の共通ポートはコントローラの左右、Pリアクターの抽出ポートは炉殻の代わりに置きます。Pリアクターのリング交差点6か所はジャイロ駆動部、斜め45度の12か所は**炉心安定化コイル**です。

## 探索で得られるもの

| 遺構 | 主な回収物と用途 |
| --- | --- |
| 地表観測拠点 | 観測ログと劣化した制御ユニット。超伝導・ミュオン技術への入口 |
| 研究棟 | 量子データ片と劣化した冷却原子トラップ。量子技術に必要 |
| 封鎖培養施設 | 培養データと劣化した時間結晶の種。時間結晶とエキゾチック物質に必要 |
| 最終実験施設 | アノマリー・サンプルと初回の休眠した特異点の種。ホライズン・ウォーデンが守る |
| 沈んだ炉心区画 | 止まった二基目の炉。エキゾチック物質・ジェット凝縮体・H凝縮体。エルゴ球の大蛇が守る |

地上に建つのは地表観測拠点だけで、研究棟は浅い地下、封鎖培養施設は深い地下、最終実験施設はさらに深い地下、沈んだ炉心区画はそのまた下（Y−60〜−54あたり）に埋もれています。探索コンパスははじめ地表観測拠点しか探せません。攻略した（保管庫を自分で開けた）遺構の保管庫をスニークして右クリックすると調整され、次の遺構も探せるようになります。探す遺構はスニークして右クリック（空中）で切り替えます。オペレーターは `/singulo ruin <遺構> [位置]` で遺構をその場に建てられます。重力波検出器とニュートリノ・スキャナーも探索を助けます。保管庫が空になると、既定では観測拠点・研究棟はゲーム内7日、培養施設・最終実験施設・沈んだ炉心区画は14日で内容が再生します。

各遺構には、次の段階の鍵でしか開かない**封印コンテナ**があります（磁気錠 → 量子錠 → 時間錠 → 特異点錠）。鍵は精密組立台で作り、1回で使い切ります。中には素材や色つきの照明、ときにはここでしか手に入らない道具（オーバークロック・チップ、重力ブーツ、触媒安定化剤、次元ポケット）が入っています。封印中に無理に壊すと中身ごと失われます。段階が進めば自分でもコンテナを作れ、鍵を持ってスニークして使うと封印できます。

自動探査機は、プレイヤーが保管庫を開いて発見した遺構にしか飛べません。既定の段階4ステーションが自動化できるのは地表観測拠点で、封鎖培養施設・最終実験施設・沈んだ炉心区画は常に手動探索です。記録片を端末で解読し、解読した記録を読むと、ハンドブックに旧文明の物語が加わります。

## アンドロイド

どの遺構にも、壁際に**遺構の印刷台**があります。サバイバルのプレイヤーが近づくと、台の型のアンドロイドを2〜3体、台の上へ下から積み上げるように印刷して出撃させます。全部倒すと、その型の**小型クリスタルメモリ**が台の上に出ます（台はゲーム内1日休みます）。

| 型 | 主な技 |
| --- | --- |
| 光刃型「ルミナ」 | 残像を残して詰め寄る瞬歩斬り、床から立つ光の柱（予告の輪から出る）、回転斬り |
| 鞭型「ヴェルナ」 | 約6ブロック届く鞭打ち、巻きつけて引き寄せる絡め取り、床を走る衝撃波（跳べばかわせる） |
| 光剣型「ソレイユ」 | 踏み込む突き、刃が伸びる横薙ぎ、飛ぶ斬撃波。打たれると正面に光の盾を張り、さらに打つと斬り返す |

アンドロイドには充電があり、大技10回ほどで切れます。近くの印刷台へ戻るか、昼の空の下ではソーラーパネルを広げ、夜や屋内では座り込んで充電します（印刷台5秒・太陽光10秒・座り込み14秒）。充電中は攻撃してきません。

**自分のアンドロイド：** 段階2の精密組立台で**アンドロイド組立ステーション**とアンドロイドキットを作ります。ステーションに小型クリスタルメモリ（減らない）とキット（印刷ごとに1つ）を入れて電力を送ると、上に護衛のアンドロイドを1体印刷します（1回 40,000 FE）。倒されても、キットがあれば印刷し直します。

- 護衛は敵対モブだけを狙い、プレイヤーやボスとは戦いません。プレイヤーとボスの攻撃では傷つきません。
- 動き方は迎撃（ステーションのそば）・徘徊（16ブロック以内）・追従（持ち主についていく）。体力が「戻る体力」を下回るとステーションへ戻り、5秒で修理と充電をします。
- 追従中は、**アンドロイド用無線充電器**（満タンで30回分）を持っていれば、持ち主のそばでついて歩きながら充電します。
- 追従中に戦うかは「ついていくだけ」と「護衛する」で切り替えられます（アンドロイドの画面のモードの札をクリックしても切り替わります）。
- ステーションの許可証スロットに**シールド許可証**を入れると、持ち主と登録した人だけがステーションとアンドロイドの画面を開けます。追従する人も、持ち主か登録した人から選べます。
- アンドロイドを右クリックすると持ち物の画面が開きます。**自己修理キット**（体力が減ったら1つ使って半分直す）と、防具のエンチャントが付けられる**アンドロイド用装甲板**を積めます。
- **アップグレード**：ステーションに**生産アップグレード**を積むと、2体まで印刷します（上で充電できるのは1体ずつで、もう1体はそばで待って交代）。アンドロイドの画面の「装備と持ち物」のページ（名前の左のボタン）では、**バッテリーアップグレード**（1個につき充電 +50%、2個まで）、**バックパックアップグレード**（3段階で、持ち物 +12・+18・+24スロット。上の段階は1つ下から作る）、**採掘アップグレード**（採掘の作業に使う。ツルハシのエンチャントを付けられる）を積めます。持ち物は5スロットで、バックパックで増えます。
- **作業の自動化**：**アンドロイド作業指令台**（隣のチェストが素材置き場。**資材口**で増やせる）に、**作業位置カード**で**レシピ棚**をつなぎます。指令台の「記録」で記録した**レシピカード**を、作業台を記録した作業位置カードと一緒にレシピ棚に並べると、指令台から注文できます。完成品は指令台の納品箱か、名前を付けた**納品口**に届きます。素材が足りない注文はできず、途中の素材も自動で作ります。
- **加工・手順・採掘**：「記録」の**加工**モードでは、かまどや装置に入れる物（数つき）と出てくる物（副産物も）を記録し、アンドロイドが上から入れて下から取り出します（JEI の「+」でも置けます）。**手順**モードでは、投入・取り出し・採掘の手順を**手順カード**に記録します（場所はカードの中）。採掘は**採掘アップグレード**を積んだアンドロイドが、範囲のブロックを目当ての数がそろうまで掘ります（ダイヤのツルハシ相当、アップグレードのエンチャントが効きます）。**アンドロイド作業台**なら、バニラの作業台の4倍の速さで作ります。
- **登録した注文と進み具合**：注文の確認でボタンを切り替えると、注文を**登録**できます（16件まで）。**在庫を保つ**（素材置き場の在庫が決めた数を下回ったら自動で注文）、**信号で1回**（指令台にレッドストーン信号が入るたびに注文）、**信号の間 在庫を保つ**から選べます。素材が足りなければ、そろうまで待ちます。指令台は進行中の注文があるとコンパレーターに15を出します。「進行中」の注文をクリックすると、工程ごとの回数と、アンドロイドが今していることが見られます（頭の上にもアイコンが出ます。設定で消せます）。
- **作業中の反撃と挨拶**：作業中に襲われたアンドロイドは、襲ってきた相手だけを迎え撃ち、片付けたら止めた所から作業に戻ります。しばらく離れていた持ち主が近くに来ると手を振り、仲間とすれ違うと会釈し、届け終えるとうなずきます。
- **農作業と操作**：手順カードに、収穫（作物を取って植え直す）・伐採（木を丸ごと切って苗木を植え直す。**伐採アップグレード**が要る）・繁殖・毛刈り・搾乳・処理・操作（レバーのオン/オフ、ボタン、ドア）の手順を足せます。
- **止まっているとき**：アンドロイドが止まっていると、理由（ステーションの電力が足りない・行き先にたどり着けない・素材が足りない・守られたブロック・作業の範囲に対象がない・置き場がいっぱい）が、アンドロイドの画面の吹き出しと、作業指令台の注文の詳細に赤い字で出ます。**測量メガネ**を掛けると、頭の上に立ち入り禁止の印が出ます。
- **液体・ガス**：**タンクアップグレード**（2タンク、各32,000 mB）を積んだアンドロイドは、資材口の隣のタンクから液体やガスを取り、装置へ運びます。加工モードや手順の見本の欄を、バケツなどでクリックするか JEI の「+」で流体を置けます。
- **装飾**：アンドロイドの画面の3枚目「装飾」のページで、頭（リボン・髪飾り・ベレー帽・ヘッドドレス）・背中/腰（マント・マフラー・腰リボン）・手（文庫本・花束・ティーカップ・傘）に装飾を着けられます。作業台で作り、染料で染められます。
- ステーションには補充スロット（自己修理キットを自動で補充）と強化スロット（**転送アップグレード**で、倒れたときの持ち物を次のアンドロイドへ引き継ぐ）があり、ホッパーなどで搬入できます。
- 名前はステーションやアンドロイドの画面で付けられ、コンパレーターでアンドロイドの体力を読み取れます。ステーションを壊しても、新しいステーションで「リンク」すればつなぎ直せます。

**アンドロイド用のガラス：** 遮断ガラス（アンドロイドだけ通れない）と透過ガラス（アンドロイドだけ通れる）があり、それぞれ隣とつながる無地と、模様入りがあります。

## ブラックホールと、その先

最初の特異点の種を炉心制御装置に入れ、点火して、既定で10秒以内に50 GFEを供給します（平均250 MFE/t）。その後の形成演出で炉心が生まれます。点火には大容量の電力設備が必要です。受電量は送電経路で容量が最も小さいケーブルで決まり、トポロジカル導線の1経路では10秒に20 GFEしか届きません。点火中の画面には受電の速さと届く見込みが、失敗したときは足りなかった量が表示されます。

新しい炉心は**回収運転**で始まります。炉心質量を480以下に保ち、Hコレクターを入れておけばH凝縮体が5分に1個できます。最初のシンギュラリティ・コアには6個（直接4・アノマリー・サンプルの復元2）が必要です。集まったら画面の「回収運転」を切ると発電運転になります。育ちすぎた炉心も、回収運転にすると毎秒2ずつ質量を放出して戻ります。

運転中は質量ペレットを投入し、質量とスピンを管理します。スピンは降着効率、質量は燃料の投入上限などに関わります。コレクターを使うと、条件に応じてジェット凝縮体、ホーキング凝縮体、エキゾチック物質を得られます。ペレットからの成長には上限がありますが、他の物質を飲み込ませすぎると炉が崩壊し、野良ブラックホールが残ることがあります。

**ボスと再戦：** 研究棟には残響の番人、封鎖培養施設には重力の澱、最終実験施設にはホライズン・ウォーデン、沈んだ炉心区画にはエルゴ球の大蛇がいて、倒すまで保管庫は力場で封鎖されています。攻略後は、特異点封入台で作る覚醒核（覚醒の記録核・残響核・重力核・渦核）を封印コンソールや番人の封印核に使うと、覚醒した強化版（体力2.5倍・攻撃1.5倍・技の間が短い）と何度でも再戦できます。勝つと通常の報酬に加えてオーバークロック・チップなどが出ます。挑戦をやめて部屋を離れると、使った核は戻ります。

**記録の断章：** 覚醒した3体の番人（残響の番人・重力の澱・ホライズン・ウォーデン）は記録の断章を、エルゴ球の大蛇は渦の断章を落とします。4つの断章を特異点封入台で束ねた「終焉の記録」を最終実験施設の封印コンソールに使うと、時間の場で眠っていた何かが目を覚まします。力場で部屋が閉ざされ、決着がつくまで出られない戦いです。重力を変える技もあるので、落下への備えをしてから挑みましょう。創世炉に断章は1つしか要らないので、両方を目指すなら断章を余分に集めておきます。

**協力プレイ：** ボスは部屋にいる挑戦者の人数に合わせて強くなります（1人増えるごとに体力+50%、技の間も少し短くなる。6人まで）。全員の攻撃がそれぞれ通るので、大勢で挑むほど早く倒せます。落とす物は、戦いが始まったときの人数ぶん出ます（あとから加わった人のぶんは増えません）。サーバー設定 `bossHealthPerPlayer`・`bossMaxScaledPlayers`・`bossLootPerPlayer` で調整できます。ボスはその時点で手に入る装備でぎりぎり勝てる強さに合わせてあり、サーバー設定 `bossHardMode` をオンにするともっと強くなります。ボスが落とす物は床の封印核（ホライズン・ウォーデンは封印コンソール）の上に出て、経験値は部屋にいる挑戦者で等しく分けて直接入ります（合計は落とす物と同じく戦いが始まったときの人数ぶん。修繕も効きます）。

終盤の装置では、拠点のシールド、対応装置の時間加速、チャンクの保持、重力操作ができます。メトリック・ドライブは持ち物に入れて使い、Curios装着枠は必要ありません。ワームホールは一対の口を生成・固定化・配置し、近くのポートで遠隔の電力・アイテム・液体をつなぎます。口の維持にはエキゾチック物質が必要で、接続先のチャンクもロードされている必要があります。

## 最終目標：創世炉

旧文明は「すべての質量をエネルギーに」変えようとして滅びました。創世炉はその逆で、ブラックホールの電力から宇宙をひとつ生み出します。

1. **組む：** 創世炉の核のまわり、同じ高さに創世炉の枠を8個置きます（核から十字方向に3マスの4か所と、斜めに2マスずつ離れた4か所）。斜めの4つの枠の上に、創世炉の柱を3段ずつ（計12個）積みます。枠は1回の加工で2個できます。ホロ投影機と組み立ての杖にも対応しています。
2. **原初の種：** 渦の断章を材料に特異点封入台で作り、核に使います。
3. **種火：** 1.5 TFE を注ぎます（1 tickあたり最大1 GFE。Pリアクターを全開にして1分あまり）。
4. **安定化：** 100 MFE/t を保ったまま、進めている時間で約4分です。ときどき「暴走の兆し」の警報が鳴り、4秒後に暴走が始まります。暴走している間は投入を止めてください（核を素手で使って開く画面のスイッチか、核への赤石信号）。止めずにいると不安定度が上がり、100%に達すると宇宙が崩れて進みが戻ります。止めている間も蓄えから維持の電力は使われ、重力の漏れ・記録の残響・引力の波といった異変も起きます。シールドの中では暴走と異変が弱まり、Tシリンダーの加速の場の中では速く進みます。
5. **誕生：** 約30秒の演出のあと、生まれた銀河がオーバーワールドの夜空に昇り、全員の空に見えるようになります。

宇宙を生んだ炉では**質量生成**ができます。画面の枠に作りたい物を登録すると、電力からその物を作り出します。1個に要る電力は `質量 × 1 GFE × 10^希少度` で、希少度は0（石・木など）から4（ネザースター・エリトラ・ドラゴンの卵など）まであります。作るのは素の品物で、見本のエンチャントや名前は写りません。生成した物を加工してPリアクターに入れても、電力が増えることはありません。

核を壊して置き直しても、宇宙の記憶（段階・銀河・作る物）は残ります。ただし、溜めた電力と作りかけの進み具合は失われます。作れる物はデータパック（`data/<名前空間>/mass_synthesis/`）で変えられます。

## つまずいたら

- **装置が動かない：** 電力、材料、触媒のティアと残量、出力の空き、必要な液体を確認します。マルチブロックは形とポートの場所も確認してください。
- **道具の操作が違う：** 慣性制御ガントレットは右クリック長押し。グラビトン・マニピュレーターは左クリック長押しで操作し、浮遊中に右クリックをためて離すと投げます。操作キーはゲーム内の設定で確認できます。
- **発電機が止まっている：** 蓄電がいっぱいなら「待機中」です。電力を使えば再開します。
- **工場を離れると止まる：** 未ロードのチャンクは処理されません。ワールドライン・アンカーを使う場合も、電力と触媒の維持を確認します。1人が同時に動かせるアンカーは既定で8台までです（サーバー設定 `maxAnchorsPerPlayer`、0で無制限）。
- **危険を知りたい：** ブラックホールには引力・潮汐ダメージ・事象の地平線による消滅があります。水素漏れは火気の近くで爆発し、大きな加速器は低蓄電時にストレンジレットを漏らすことがあります。磁気瓶や保護設備を準備しましょう。

標準テクスチャは16×16です。組み込みリソースパック **Singulo HD** を有効にすると32×32へ切り替えられます。粒子加速器は辺と角が自動でつながり、稼働中は光が周回します。

難易度はサーバー設定 `preset` で変えられます。`casual` はネザースター不要・触媒寿命2倍・遺構の再生とウォーデンの体力が半分・殻の圧縮量が半分、`expert` はスター2倍・触媒寿命0.75倍・修復2回まで・殻の圧縮量1.5倍・点火エネルギー2倍です。スター数・殻の材料・育成時間などの個別の設定も、既定値から変えればレシピとJEIに反映されます。

この説明書は現行実装と既定設定に基づきます。レシピは [一覧](recipes/README.md)、仕様確認の記録は [照合記録](documentation-audit.md)を参照してください。サーバー設定やデータパックによる変更は、ゲーム内の表示・レシピを優先してください。


## 装置の移設と自動排出

鋼鉄インゴット3個・銅インゴット2個・基礎回路1個で移設レンチを作れます。対応する装置をスニーク＋右クリックすると、中身・液体・電力・進捗・面設定を保持して回収します。マルチブロックはコントローラだけを回収します。対応範囲はゲーム内ハンドブックの「電力と輸送 → 移設レンチ」を参照してください。

通常の加工装置の自動排出は初期オフです。「面」の全体スイッチをオンにすると、許可した出力可能な面から搬出します。面にカーソルを合わせると隣接ブロック名が分かります。新規生成の地下研究所では、専用の貨物昇降室に搬入出立坑がつながり、主立坑と両方が必ず生成されます。

未使用の観測ログ・量子データ片・培養データや復元部品は、同じ状態のものを64個まで重ねられます。装置の入力枠には1個だけ入り、Shiftクリックでも1個だけ投入します。使用途中のものは重なりません。

加工で使い切った制御ユニットなどの復元部品や原本は、使用後の状態のまま出力に回ります。出力枠が埋まっている間は入力枠で待機し、そこからもホッパーやアイテムパイプで回収できます。自動搬出をオンにすると隣接先へ搬出します。修復用に投入した部品は自動で搬出しません。
