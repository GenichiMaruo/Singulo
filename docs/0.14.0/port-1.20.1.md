# 0.14.0 — Minecraft 1.20.1移植

対象: Forge 47.4.26 / NeoForge 47.1.106 / Java 17。移植元は公開済みの`v0.14.0`（`dda229c7`）。両ローダーを同じ`1.20.1`ブランチで保守する。

## 内容と互換性

- ドローン輸送3種、位相シフト、ポートの自動発送、アンドロイド連携、荷物の保存と復旧、所有者ごとの索引を移植。
- 容量アップグレード専用枠、JEI 15の配置・転送ボタン、面設定とポップアップの改善を移植。
- 全370レシピを1.20.1形式へ正規化し、移植元のハッシュと照合する。材料量・配置・電力・触媒条件を独自に変更しない。
- 梱包箱の中身は1.20.1のアイテムNBTで保存。空箱は16個まで、梱包後は1個のみ。空にした後は状態を除去して新品と重なる。
- 1.20.1にはスタック単位の入れ子制限APIがないため、シュルカーのスロット・搬入面・Forgeの在庫窓口とバンドルに対応する制約を追加。空箱は収納可能、梱包済みの箱は収納不可。
- ドローンのチャンク解放をForgeの`onRemovedFromWorld`へ対応させ、荷物を飛行記録側に保持する。
- 隣接在庫はLazyOptionalの失効を監視し、窓口が変わるまでアンドロイド用ビューを再利用する。
- 通信プロトコルは6。クライアント・サーバーを両方更新する。

## 検証構成

CIは4ジョブを維持する。ForgeとNeoForgeで通常GameTest全656件・GUI242画面を検証し、共通のMekanism連携2件と描画連携をForgeで実行する。JEI 15の実転送・ポップアップ・容量3段階の5言語表示はForgeの既存ジョブ内で一度実行する。

公開では成功したCIと同一GitツリーのJARを使用し、再ビルドしない。GitHub ReleasesにはJARを添付しない。

## 移植レビューで修正した点

資材口優先テストの追加チェストが、1.20.1で余白を取ったアンドロイド出現位置と重なっていた。追加した資材口・チェスト・精密組立機にも同じ座標変換を適用し、通行可能な配置で優先順位を検証する。配置修正後はクラス単独91件が成功したが、全件CIでは同じ1件の失敗が残った。新規の優先順位テスト3件にも既存のアンドロイド試験と同じ単独バッチ・フィクスチャ隔離を適用し、他の試験と同時に施設やエンティティを動かさない。修正後の全件CIを公開条件とする。

- JEI 15の全レシピ配置、転送の実適用と重複防止、ポップアップ操作、5言語×3段階の容量スロット、ドローン3種の実描画検査成功（21画面）。
