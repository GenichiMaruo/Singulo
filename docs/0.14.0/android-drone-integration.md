# アンドロイドとドローンの連携

対象: `feature/0.14.0` / Minecraft 1.21.1 / NeoForge。アンドロイドは拠点内の製作・運搬、ドローンは拠点間の輸送を担当する。追加装置・レシピ・リンク操作は増やさない。

## 接続

1. **着荷品を使う**: アンドロイド資材口にドローン発着ポートを隣接させ、その面の「荷物」を出力にする。指令台は受取品だけを利用可能な素材として数える。発送待ち荷物、未開梱の箱、入力専用の面から取り出せない物は数えない。
2. **完成品を送る**: アンドロイド納品口に発着ポートを隣接させ、荷物の入力を許可する。完成品がポートへ入り、既存のしきい値・行き先を使って自動発送できる。荷物が満杯なら完成品は納品口に残り、空きができると再開する。
3. **空き箱を循環させる**: 受取側ポートの「空き箱」タブで、回収する面を出力にする。資材口からアンドロイドが回収するか、パイプ・ホッパー・自動排出を使う。返送用ポートの搬入面は「空き箱」を無効、「荷物」を入力にし、空き箱を返送貨物として入れる。輸送に使う箱は別の面から補充し、自動発送の行き先を元の拠点に設定する。

空き箱の設定は予備の箱スロットを対象とする。全て搬出すればそのポート自身の発送用箱もなくなるので、受取用と返送用のポートを分けると管理しやすい。箱の返送にも通常どおり電力・輸送用の箱・ドローンが必要。

## 保持する仕様

- 空き箱は初期設定では全方向入力のみ。荷物・空き箱の自動排出スイッチは独立し、いずれも初期設定オフ。
- 荷物の面設定、シミュレーションによる挿入・取出し、部分納品、保存復元を維持する。
- アンドロイド用の在庫表示だけを取出し可能な物に限定する。通常のホッパー・パイプ向けインターフェースは発送欄への投入と着荷箱の回収を引き続き提供する。予備箱の取出しは明示的に設定した出力面だけに許可する。
- ポートごとの方向別ビューを再利用し、遠方の在庫走査やチャンク強制読込を追加しない。

遠隔拠点の不足を受けて自動で製作注文を発行する仕組みは今回の範囲に含めない。追加する場合は製作中・発送待ち・輸送中の予約を共通管理し、同じ不足による二重発注を防ぐ。
