# 変更後の再計算（0.3.1 予定）

[analyze.py](../analyze.py) を変更後の `tools/recipes.py` で実行した出力。比較は [対応記録](../RESOLUTION.md) を参照。

- 評価時の `assert len(blocked)>=4`（進行停止レシピが残っていることの確認）は、停止レシピが0件になったため外して実行した。
- `calculation-results.json` の `shells` 節は計算式に旧レシピ（炉殻12枚・金属の核2個）が直書きされているため、変更前の値のまま。殻の数と岩石・金属は `cumulative` 節（設備バスケット）の値が正しい。
- Pリアクターの時系列モデルは変更していない（回収運転は含まない）。
