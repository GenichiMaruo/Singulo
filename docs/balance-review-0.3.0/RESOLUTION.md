# 0.3.0 バランス評価への対応記録（0.3.1 予定）

対応日：2026-10-11　対象ブランチ：`bug-fix-0.3.0-1.21.1N`（評価対象 `b45f478` から）  
目標難易度：**探索と工場づくりを両立する中難度**。攻略後は「高難易度＋」の再戦を任意で用意する。

[課題一覧](issue.md)・[評価報告書](README.md) は評価時点の記録としてそのまま残し、ここに何をどう変えたかをまとめる。
評価用の計算（[analyze.py](analyze.py)）を変更後のレシピで再実行した結果は [after-0.3.1](after-0.3.1/) に置いた
（`blocked_recipes` が空、`config_no_main_java_reference` が空になったことを含む）。

> **追記（マージ後レビュー 176ee06 への対応）：** 育成負荷の「136→112分」は、触媒の寿命を分数で合算したモデルの値で、
> 実物の触媒を1個ずつ数えると点火前は新品10個・124分・台になる（SNG-026）。`analyze.py` は現行ソースのまま実行でき、
> 殻の数値もレシピから読むように直した（SNG-030）。マージ後に見つかった不具合（SNG-021〜025）の対応は
> [マージ後レビューへの対応記録](../merge-review-176ee06/RESOLUTION.md) にある。

> **検証の範囲：** この環境からは NeoForge のMavenに接続できず、Gradle ビルドと GameTest は実行できていない。Java は構文解析
> （javac のパース段階）まで、データ生成（`tools/gen_data.py` の検証・翻訳チェック）とレシピ計算は実行済み。追加した GameTest
> （`BalanceGameTests`、`ReactorGameTests`・`BossGameTests` の追加分）は、手元の `gradlew runGameTestServer` で確認してほしい。

## 時間結晶モジュールの仕様

- 精密組立台：時間結晶触媒（触媒枠）の寿命 36,000 tick ＋ 光格子基板1 ＋ 鋼板2 → 時間結晶モジュール1（10秒・2 kFE/t）。
- 触媒は使用回数の材料として扱うので、残り寿命が足りない結晶では照合しない。新品（54,000 tick）なら18,000 tick（15分）残り、そのまま運転に使える。
- 切り出す量は新品の寿命の2/3（既定で30分）。寿命の設定やプリセットを変えると比例して変わる（176ee06 のレビュー SNG-022 で、固定30分から変更）。

## 攻略後の再戦：覚醒したホライズン・ウォーデン

- **呼び出し：** 特異点封入台で「覚醒の記録核」（H凝縮体1・エキゾチック物質4・量子演算モジュール1、60秒・200 kFE/t）を作り、最終実験施設の封印コンソールに使う。保管庫が開いていても呼べる。点火後でないと作れないので、自然に「最終攻略後」の挑戦になる。
- **強さ：** 体力×2.5（既定3,000相当、設定 `awakenedWardenHealthMultiplier`）、与えるダメージ×1.5（`awakenedWardenDamageMultiplier`、光弾・ビーム・特異点など出どころがこの個体の攻撃すべて）、技の間×0.75、フェーズ2が体力80%・フェーズ3が45%から、歩く速さ×1.15。ボスバーは紫、胸から菫色の炎。
- **報酬：** オーバークロック・チップ2個（ほかでは封印コンテナからしか出ない）、エキゾチック物質8個、H凝縮体2個、経験値500。呼び出しの材料より多く返るので、繰り返し挑む意味がある。進捗「目覚めた地平線」。
- **やり直し：** 挑戦者が部屋を離れると、守護機は封印に戻り、記録核はコンソールの上に返る（材料を失わない）。

## 追加・更新した GameTest

- `BalanceGameTests`：モジュール4個を搬入口から入れて炉心制御装置ができる／寿命が30分未満の結晶からはモジュールができない／満充電で待機し触媒が減らない・減ると再開／アンカーの上限／既定設定ではレシピJSONを変えない。
- `ReactorGameTests`：回収運転で質量が480以下に保たれる／育ちすぎた炉心が毎秒2ずつ質量を放出する。
- `BossGameTests`：覚醒の記録核で体力2.5倍の守護機が起きる／やめると記録核が返る。
- 既存テストを新しい値に合わせた（量子熱機関の下位出力25%、縮退熱炉5 MFE/t、殻の金属の核1個）。
