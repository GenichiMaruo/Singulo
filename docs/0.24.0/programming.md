# アンドロイドのプログラム（0.24.0）

プログラムカードに Python に似た書き方で書いた文の通りに、アンドロイドが動く。組立ステーションの動き方「コード」（`RuinAndroid.MODE_PROGRAM` = 4）で使う。

## 使い方

1. プログラムカード（段階2の作業台。手順カード・基礎回路・レッドストーン2）を手に持って使うと、書く画面（`client/ProgramEditorScreen`・`client/CodeEditor`）が開く。Esc か「完了」で保存、「取り消し」で保存せずに閉じる。保存は `SaveProgramPayload` で手に持ったカードの `singulo:program`（文字列、16,000文字まで）に書く。書き方の誤りがあっても保存できる。
2. ステーションの動き方を「コード」にすると、巡回路の欄（8つ）が場所の欄になり、下の段の左にプログラムカードの欄（`SLOT_PROGRAM`。古い保存と番号がずれないよう、最後のスロット）が出る。
3. 場所は巡回路の欄の作業位置カード。金床で付けた名前（前後の空白は除く）か、欄の番号の `p1`〜`p8` で呼ぶ。`pos(x, y, z)` でも指せる。

ステーションは毎秒（ほかの設定と同じ `sync`）、カードの文と場所を受け持つアンドロイドに渡す。文か場所が変わったら、プログラムを最初から動かし直す。「もう一度」（`BUTTON_PROGRAM_RESTART`）でも最初から動く。

## 書く画面

`client/ProgramEditorScreen`（文の欄は `CodeEditor`、候補とヒントは `ProgramAssist`、関数・メソッド・ひな形の一覧は `ProgramHelp`）。

- 上の段: 候補・ヒントの切り替え（`singulo-client.toml` の `programCompletion`・`programHints`）、もう一度（ステーションから開いたとき）、完了（保存して閉じる。Esc も同じ、Ctrl+S は保存だけ）、×（保存せずに閉じる。変えていれば2回押す）。
- 右のタブ: 関数（分類と検索。クリックで入れる）、場所（ステーションの巡回路の欄。クリックで名前を入れる）、例（ひな形6つ。欄が空なら置き換え）、出力（動いている様子と、最近の say の言葉8つ）。
- 下の段: 書き方の誤り（クリックでその行へ）、なければステーションにない場所の名前、最後の say の言葉、カーソルの位置と文字数。
- 候補: 打っている語に合うキーワード・関数・自分で定めた関数と変数・メソッド（`.` のあと）。文字列の中では、場所を受け取る引数なら場所の名前、物を受け取る引数なら物の ID（ID か表示名の一部で合わせる。`#` でタグ）。↑↓で選び Tab / Enter で入れる、Esc で閉じる、Ctrl+Space でいつでも出す。関数を選ぶと `(` も入る。
- ヒント: カーソルのある呼び出しの引数を並べ、今の引数に下線を引く。組み込みの関数は説明も出す。
- ステーションの「編集」から開くと、閉じたときにステーションの画面へ戻り、保存はステーションのカードへ（`SaveProgramPayload` の containerId）。動いている行は、文を変えていないあいだ緑の印で出す。

## 言語

`android/program/`。Minecraft の世界に触れる部分は `Vm.Host` を通す（言語だけを GameTest で確かめられる）。

| 部分 | クラス |
|---|---|
| 語に分ける（字下げは INDENT / DEDENT。タブは4つの空白、かっこの中と行末の `\` で文が続く、`#` はコメント） | `Lexer` |
| 読みながら命令に訳す（再帰下降）。呼んだ関数の有無と引数の数は訳すときに確かめる | `Compiler` |
| 命令・定数・名前・関数の表 | `Code` |
| 動かす（手数の上限、動きを待つ、誤りの行） | `Vm` |
| 値の計算（Python に合わせる） | `Values` |
| 値だけの関数・メソッド・属性 | `Builtins` |
| 呼べる関数と引数の数（host・action の印） | `Library` |
| 誤り（行・翻訳キー `program.singulo.error.<key>`・引数） | `ProgramError` |

書けるもの:

- 文: 代入（`=` と `+= -= *= /= //= %= **=`。リストの添え字にも）、`if / elif / else`、`while`、`for 名前 in 式`、`def`（いちばん外側だけ）、`return`、`break`、`continue`、`pass`、`global`。`:` のあとの同じ行に1つの文も書ける。
- 式: `or / and / not`、比べる（`== != < <= > >= in not in is is not`。続けて比べるのは不可）、`+ - * / // % **`、単項の `- +`、呼び出し、添え字、リスト、場所の `.x .y .z`。
- 値: None・真偽・整数（64ビット。あふれたら誤り）・小数・文字列・リスト・場所・range。
- メソッド: リストの `append pop insert remove index clear`、文字列の `upper lower strip startswith endswith replace split join`、場所の `offset up down north south east west`。

書けないもの（`unsupported` の誤り）: `import`・`class`・`lambda`・`try`・`with`・キーワード引数・`a = b = c`・`a < b < c`・入れ子の `def`。辞書・タプル・スライスはない。

関数の中で代入した名前はその関数の変数（`global` にした名前を除く）。読むときは関数の変数、なければ外側の変数を見る（Python の UnboundLocalError はない）。関数はどこで定めても呼べる。

上限: 呼び出しの深さ32、式の途中の値256、1つの範囲の変数256、リスト1,024、文字列4,096文字、文16,000文字・命令20,000。

## アンドロイドの関数

`android/AndroidProgram`（`Vm.Host`）。動き（action）は時間がかかり、終わるまでプログラムが待つ。調べる関数はすぐ返る。

| 関数 | 中身 |
|---|---|
| `go(p)` | 立てる場所ならそのブロックの真ん中（0.3 以内）へ、ブロックならその横へ歩く。着いたら True、20秒たどり着けなければ False |
| `take(p, 物, 数)` | 入れ物の下の面（なければ面なし）から持ち物へ。物・数は省ける。持ち物に入る分だけ取る（落とさない）。取った数 |
| `put(p, 物, 数)` | 持ち物から入れ物の上の面（なければ面なし）へ。入れた数 |
| `use(p)` | ボタンは押す、レバーは切り替える、ほかは右クリック。使えたら True |
| `lever(p, on)` | レバーを入（True）・切（False）にする。もうその向きなら歩いて行かずに True。レバーでなければ `not_lever` の誤り |
| `mine(p)` | 採掘アップグレードが要る（なければ誤り）。ダイヤのツルハシ相当で1つ掘り、落ちる物がみな持ち物に入るときだけ壊す |
| `wait(秒)` | 待つ（1 tick〜1時間） |
| `attack(m, p, r)` | モブ m を狙いにして、型ごとのいつもの戦い方で戦う。倒したら True、いなくなった・範囲（p から r ブロック）を出た・1分たった・はじめから範囲の外なら False。p・r は省ける（範囲なし） |
| `home()` | ステーションの上へ戻る |
| `say(…)` / `print(…)` | 持ち主に送る（たまる数8、0.25秒に1つ戻る。超えた分は送らない）。最後の言葉はステーションに出る |
| `count(物)` / `count_at(p, 物)` / `free_slots()` | 持ち物・入れ物の数、空いたスロット |
| `block(p)` / `redstone(p)` | ブロックの ID（読み込まれていなければ None）、受けている信号 |
| `here()` / `station()` / `point(名前か番号)` / `points()` | 場所 |
| `is_day()` / `time()` / `charge()` / `health()` | 昼か、一日の時刻、充電と体力（%） |
| `mobs(p, r, 絞り込み)` | p から r ブロック（省くと5、16まで）のモブの一覧、近い順に64まで。絞り込みは下の書き方（省くか None なら全部） |
| `matches(m, 絞り込み)` | モブが絞り込みに合えば True（いなくなったモブは False） |
| `distance(a, b)` | 2つの場所（ブロックの中心）かモブ（足元）の間の距離 |
| `auto_fight(on)` | False にすると、自分で敵を探す・打たれて仕返しするのをやめ、attack の相手とだけ戦う（ワールドを開き直すと True に戻る） |
| `send(名前, 値, r)` | r ブロック（省くと16、64まで）以内の仲間へ知らせを送る。届いた数 |
| `receive(名前)` | 届いた知らせを古い順に1つ取り出す（名前を省けば何でも）。なければ None |

モブ（`mobs()` の結果）の属性: `.name`・`.type`（`"minecraft:zombie"` など）・`.health`・`.max_health`・`.alive`・`.hostile`・`.baby`・`.named`（名札）・`.pos`・`.x .y .z`。

絞り込み: 文字列1つか、文字列のリスト。`"hostile"`（敵対モブ）・`"animal"`（動物）・`"all"`、モブの ID（`"zombie"`・`"minecraft:skeleton"`。`minecraft:` を省ける）、エンティティのタグ（`"#minecraft:undead"`）。頭に `!` を付けると除く。除かないものが1つでもあれば、そのどれかに合うものだけ残り、そこから除くものを取り除く（`["hostile", "!creeper"]` は敵対モブのうちクリーパー以外、`["!villager"]` は村人以外のすべて）。分からない ID・タグは `bad_filter` の誤り。いなくなったモブは `.alive` と `.type` だけ読める（ほかは `mob_gone` の誤り）。戦えないのは、自分・護衛のアンドロイド・持ち主と許可証の登録者が飼っている動物・ボス（対番人モジュールがなければ）。プレイヤーは `mobs()` に出ない。

物は `"coal"`（`minecraft:` を省ける）・`"singulo:steel_ingot"`・`"#c:ingots"`（タグ）・None（何でも）。

## 仲間と動く（知らせ）

`send` は、送ったアンドロイドから r ブロック以内の、動き方「コード」の護衛のアンドロイドのうち、同じ持ち主か、どちらかが相手の持ち主を許可証に登録しているものへ届く（自分には届かない）。受ける側は知らせを16までためる（あふれたら古いものから捨てる。プログラムをやり直すと空になる）。値は数・文字・真偽・None・場所・モブ・それらのリスト（入れ子は4段まで）で、リストは写しを送る（`cannot_send` の誤り）。名前は1〜32文字（`bad_topic`）。

知らせ（`receive()` の結果）の属性: `.topic`（名前）・`.data`（送った値）・`.pos`（送ったときのアンドロイドの場所）・`.sender`（その名前）。モブを送れば、受けた側もそのモブを `attack` できる。

```python
post = point("p1")
auto_fight(False)
while True:
    go(post.up())
    enemies = mobs(post, 8, "hostile")
    if enemies:
        send("enemy", enemies[0], 32)       # 近くの仲間に知らせて、自分も戦う
        attack(enemies[0], post, 12)
    else:
        msg = receive("enemy")
        if msg and msg.data.alive:          # 知らせを受けたら、知らせた見張りの所の敵を倒しに行く
            attack(msg.data, msg.pos, 12)
    wait(0.5)
```

敵が来たらレバー（ボタンなら `use(p)`）:

```python
while True:
    if mobs("p1", 10, "hostile"):
        lever("p2", True)
    else:
        lever("p2", False)
    wait(1)
```

## 守りと負荷

- 場所はステーションから横・高さとも64ブロック以内、同じ次元だけ（`too_far`・`no_station` の誤り）。読み込まれていないチャンクは読み込まない。動きは失敗、調べると空・0・None。
- 取る・入れる・使う・掘るは、ステーションの持ち主として確かめる。シールドの許可証（`ShieldTowerBlockEntity.locked`）と、ほかの mod の守り（`PlayerInteractEvent.RightClickBlock`、掘るときは `BlockEvent.BreakEvent`）が取り消せば、何もしない。
- 1 tick に400手まで（アンドロイドの関数の呼び出しは1回10手）。終わらないループでも、その tick で返る。
- 掘ると6、使うと1の充電を使う。充電が切れると充電に戻り、戻ったら続きから動く。

## 戦う

attack はプログラムの Goal を止め、相手を狙い（`setTarget`）にして、型ごとの戦い方の Goal に戦わせる。`AndroidProgram.watch`（`RuinAndroid` の毎 tick）が、相手が倒れた・いなくなった・範囲を出た・1分たったのを見て狙いを外し、結果をプログラムに渡す。attack の相手は `guardTargets`（狙いを外さない）と `canHit`（技を当ててよい）で敵と同じに扱う。`auto_fight(False)` のあいだは、`HurtByTargetGoal` と `NearestAttackableTargetGoal` を止め、attack の相手でない狙いは外す。技（範囲の斬り・光柱など）も attack の相手にだけ当てる（`canHit`）。絞り込みで除いたモブや範囲の外のモブを巻き込まない。充電・修理（`PowerGoal`・体力が減ったときの戻り）はいつもどおり。

持ち場の見張り（「例」の「持ち場で見張る」）:

```python
post = point("p1")
auto_fight(False)
while True:
    go(post.up())
    for m in mobs(post, 5):
        attack(m, post, 5)
    wait(0.5)
```

光刃型は、近づくのをやめる距離（3.2）が通常の斬りの届く距離（2.8）より遠く、2.8〜3.2 の相手には寄らずに空振りしていた。寄る距離を `SWING_REACH`（2.6）にした。

## 止まる・やり直す

- 戦い（狙う相手がいる）・充電・修理のあいだはプログラムの Goal（優先度2、作業指令台の作業と同じ）が止まる。歩いていた動きは、戻ったときに続きからやり直す（掘りかけのブロックは最初から）。
- プログラムを動かしているあいだは、暇なときの充電・修理への戻りと暮らし（`AndroidLife`）をしない（`RuinAndroid.busy()`）。作業指令台の作業は受けない。
- 変数は保存しない。ワールドを開き直す・アンドロイドを印刷し直すと、最初から動く。
- 誤りで止まると、持ち主に `program.singulo.stopped` で知らせ、ステーションの欄の枠が赤くなる。様子は `D_PROGRAM`・`D_PROGRAM_LINE`、誤りの説明と最後の言葉は更新タグの `program_message<枠>` で画面へ送る。

## 確認

- `ProgramLanguageGameTests`: 計算・文字列・制御・関数・global・場所、書き方の誤りの行とキー、動かしている途中の誤りの行とキー、動きを待つ・手数の上限。
- `AndroidProgramGameTests`: 名前の場所の入れ物の間で運ぶ、遠い場所・ない場所の名前の誤り、採掘アップグレードの有無、守られた入れ物、ステーションの場所の名前とカードの欄。
- `AndroidProgramCombatGameTests`: 本物のステーションから渡した見張りのプログラムで、範囲に入ったモブを倒して持ち場へ戻る・範囲の外のモブに手を出さない・途中で範囲を出たら False でやめる・絞り込みで除いたモブを（範囲の技でも）攻撃しない・分からない絞り込みの誤り・ブロックの真ん中まで行く・知らせを受けた仲間が敵を倒しに行く（持ち主の違うアンドロイドには届かない）・レバーを決めた向きにする。
- `ProgramAssistGameTests`: 書く画面の手助け（カーソルの所の読み取り・候補・ステーションにない場所の名前）。
