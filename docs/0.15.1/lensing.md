# 0.15.1 — 重力レンズの個数上限の撤廃

対象はMinecraft 1.21.1 / NeoForge。1.20.1への移植は未実施。

## 問題と原因

画面内のブラックホールが5個以上になると、歪みが出ないものがあった。`lensing.fsh` は固定4枠のuniformで全画面を1回で描く構造で、5個目以降は光の経路の追跡から外れ、歪みも近い4個までしか掛からなかった。

## 変更

- レンズごとに、歪みの球と円盤が届く長方形だけを奥から描く。数の上限はなく、負荷は画面に占める面積で決まる。
- 画面で重なるレンズは、画面をコピーし直して次のパスで描く。手前のレンズは奥のレンズを歪めた絵を読む。
- パスは最大16。超えた分も描くが、重なった所だけは手前のレンズが奥のレンズを歪めず上に重なる。
- 見かけの大きさによる間引きは、固定のしきい値から「歪みの範囲が1画素未満」に変更。

## 検証

`tools/review/prepare_lensing.py` のあと `./gradlew -I tools/review/lensing.gradle runClient`（`build/gametest/world/level.dat` が必要）。

| 確認 | 結果 |
|---|---|
| 15個が重なる配置（RTX 4070 SUPER、1280×800） | 全部がシェーダーで描かれ、影が残る |
| フレーム時間（同じ配置・遠景） | レンズあり 1.81 ms、なし 1.39 ms |
| GameTest | 662 / 662 |

隣のブラックホールの周りに出る破線状の黒い弧は、隣の影の反転像と判断している（弧は隣と反対側に出る）。

## 未確認

- 低性能GPU
