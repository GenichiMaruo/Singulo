# 降着ジェット鍛造炉

0.15.0 / Minecraft 1.21.1 / NeoForge。ブランチ `feature/0.15.0` で実装した。1.20.1 ブランチへの移植はしていない（API が違うため、1.21.1 版を実機で確かめてから判断する）。

## 役割

| 施設 | 何をするか |
| --- | --- |
| Pリアクター | ブラックホールで発電する |
| 創世炉 | 電力から物質を生む |
| 降着ジェット鍛造炉 | 今ある素材を、大電力で特殊加工する |

Pリアクターへの機能追加や、創世炉の別レシピにはしていない。炉心のブラックホールは発電に使わず、両極のジェットを絞ったビームで素材を鍛えるためだけに使う。ジェットは「ブラックホールの中から光が出る」ものではない。降着流の磁場をねじって両極へ押し出す、SF的な制御現象として扱う（拘束コイルの説明にもそう書いた）。

## 形（44×16×15）

形の定義は `forge/JetForgeLayout.java`。同じものを `tools/jet_forge.py` にも書き、部品の個数をレシピ表と説明に使う。2つが同じであることは GameTest `jetForgePartCountsMatchTools` が確かめる。

```
 x=0   2        11  14  17      22    27    32    35   38   41  43
  ┃杯┃ ←── ║  ●  ║ ──→ ◯ ──→ ○ ──→ o ──→ ┌────■────┐   ┃
 排熱  反対側のジェット  炉心（縦向きの円盤）  収束リング（半径5・4・3）  照射室   ビーム止め
              ▔▔▔▔▔▔▔▔▔ 炉心の下の台座（9×11、角を落とす）。制御核は手前の縁の中央
```

- 軸は y = 8・z = 8 を通る。x はジェットの軸で、0 が排熱側、増えるほど加工側になる。制御核の正面から見ると、ビームを真横から眺められる。
- 土台（y = 0）は、軸の下を通る幅3の基礎と、炉心の下の角を落とした台座（x = 10〜18、z = 3〜13）。制御核は台座の手前の縁の中央に埋め込む（初版の「土台から手前へ延びた枝の先」は、取ってつけたように見えたのでやめた）。基礎はマルチブロック搬入出ポートと入れ替えられる。
- 拘束コイルの斜め45°の8か所は、Pリアクターと同じ炉心安定化コイル。点火のとき、ここから種へ光が流れ込む。
- 排熱側の杯は3×3・高さ3の骨組みの脚で支える（初版の1本の柱は細く見えた）。ビーム止めの脚も幅3にした。
- ブラックホールの中心のマスは空気か野良ブラックホール（制御核を壊したあとに残ったもの）でなければならない。設計図はこのマスに触れない。
- 炉心の空気の球と、軸に沿った幅3のビームの通り道は空気でなければならない。通り道をふさぐと形が崩れる。

### 判定の負荷

判定する位置（部品と空気）は約1,900か所ある。

- 形成済みのときは、毎 tick 256か所ずつ確かめる（8 tick で一巡）。外れが見つかれば、その tick で崩れたと分かる。
- 未形成のときは、40 tick ごとに4つの向きを試す（最初に外れた位置で打ち切る）。
- 読み込まれていないチャンクにかかる位置があると、確かめずに待つ。チャンクを読み込まず、崩れたとも見なさない。
- 共通の `ShapeSpec` は、判定する位置の一覧を一度だけ作って使い回す。範囲を分けて確かめられるようにもした。ほかの施設も同じ判定を使い、読み込まれていない位置で失敗する。

## 炉心のブラックホール

- Pリアクターと同じ手順で作る。制御核に特異点の種（Pリアクターと同じく、シンギュラリティ・コアでもよい）を入れ、画面の「点火」を押す。点火の時間（`ignitionWindowSeconds`、既定10秒）のうちに 25 GFE（サーバー設定 `jetForgeIgnitionEnergy`）を注ぐ。点火の演出（Pリアクターと同じ16秒）のあとに重力崩壊してできる。種は使い切る。時間切れ・形の崩れでは失敗し、注いだ電力は失われ、種は残る。点火の音はPリアクターと同じ高さで鳴らす（高さを変えると音の長さが演出とずれる）。
- 点火の演出（Pリアクターと同じ3つの段）: 目覚め（〜6秒）で拘束コイルを電流が巡り、8つの安定化コイルが1つずつ灯る。注入（〜13.6秒）で安定化コイルから種へ光が流れ込み、噴射口から物質も降着円盤へ落ち始め、種が脈打ちながら膨らむ。崩壊（最後の2.4秒）で光の根元が中心へ寄り、種を囲む3つの輪が絞り込まれて黒い地平線が生まれかける。できた瞬間に閃光と3つの面の衝撃波が出て、鳴った瞬間に破裂する「ブラックホールが開く」音（`black_hole.open`）が鳴る。
- 質量は500（Pリアクターの点火直後と同じ）。引力は野良ブラックホールと同じ式で、内側（半径4.5）は逃げられない強さ（倍率0.6）。プレイヤーはクライアントで引く。地平線（半径0.33）に触れたものは飲み込む。形が崩れていても、ブラックホールがある限り引く。
- 制御核を壊すと、ブラックホールは炉心の中心に野良ブラックホールとして残る。拘束されたまま（`stable`）なので、ホーキング放射で減らない。同じ場所に鍛造炉を組み直すと取り込み、点火し直さなくてよい。

## 加工の流れと数値（仮置き）

| 段階 | 長さ | 1 tickの電力 | 見た目 |
| --- | ---: | ---: | --- |
| 予告 | 3秒 | 0 | 警告灯が回り、照射室に力場の膜が張り、素材が回収口から浮かび上がる |
| 点火 | 4秒 | 62.5 MFE | 拘束コイルに電流が巡り、降着円盤が明るくなり、両極から太いプラズマが噴き出す |
| 収束 | 4.5秒 | 125 MFE | 3つのリングが順に入るたびにひらめき、ビームが細く白くなる。リングからビームへ稲妻が走る |
| 照射 | 60秒（レシピの時間） | 250 MFE（レシピの電力） | 赤熱 → 亀裂 → 破片と光の輪 → 白熱し縮む。ビームが脈打ち、近くでは画面が細かく揺れる |
| 仕上げ | 2秒 | 0 | 閃光・衝撃波の輪・重力レンズの歪みの輪・重低音。ビームが切れる |
| 冷却 | 5秒 | 0 | 完成品が冷えて色が引き、湯気を出しながら回収口へ降りる |

- 1回は約78秒、電力は約316 GFE（照射だけで300 GFE）。受電は1 tickに最大1 GFE（サーバー設定 `jetForgeMaxInput`）、蓄えはその4倍まで（long）。
- 汎用の加工装置の受電上限（4 MFE/t）は使わず、創世炉と同じく long で受け取る。
- 比べる目安: Pリアクターは点火直後（質量500・スピン0）で約28.6 MFE/t、育てると約2.1 GFE/t まで出せる。250 MFE/t は、炉心を育てて回収運転を抜けたあとの電力で、創世炉の安定化（100 MFE/t）より重い。
- 材料はコラプサー・ビレット1・質量ペレット16（炉心の降着流）・液体ヘリウム1,000 mB（冷媒）。点火から仕上げまで、4本の梁の先の噴射口から降着円盤へ、らせんを描いて物質が流れ込む（質量ペレットを送り込んでいる演出）。
- コラプサー・ビレットは特異点封入台で作る。材料はネザライトインゴット・縮退物質殻・ジェット凝縮体4・エキゾチック物質2・ニホニウム板2。ジェット凝縮体はPリアクターのジェット・コレクターから1分に1個できる。

数値はレシピ（`tools/recipes.py` → `type: singulo:machine`、`station: accretion_jet_forge`）で決まり、データパックで変えられる。段階の長さの比（点火は1/4、収束は1/2の電力）は固定。

## 液体ヘリウムをアイテムで運ぶ

- 液体ヘリウム・カートリッジ: 空の冷媒カートリッジに液体ヘリウム250 mB（冷却塔の高さ10以上でヘリウムから詰める。空のカートリッジでタンクを右クリックしても汲める）。
- 鍛造炉は、材料の枠に入れた液体の容器（カートリッジ・液体キャニスター・他MODの容器）を5 tick ごとに1個ずつ冷媒のタンクへ注ぐ。中身が全部入り、空の容器が専用の枠（右下）に収まるときだけ注ぐ。空の容器は搬入出ポートが押し出す。ドローンで容器を運べば、パイプなしで冷媒を届けられる。

## 搬入出ポートの口

ポートは未形成でも電力・物・液体の口をいつも返し、使われるたびにコントローラの口へ渡す（`multiblock/PortProxies`）。以前は未形成の間に口を返さなかったので、Mekanism などのパイプやケーブルが読み込み直しのときや形成の直前に「口がない」と覚え、形ができてもつながらないことがあった。すべての大型機械のポートに効く。

## 止まる条件と、失わないこと

- 始める前に、完成品が出力の枠に入ること・冷媒・1 tickぶんの電力を確かめる。そろったら材料を一度に全部取り出す。足りなければ何も取らない。
- 電力不足・形の崩れ・施設の一部が読み込まれていない・コアがない・完成品の置き場がないときは、その場で止まる（段階の中の tick も進めない）。止まっている間の電力は使わない。
- 冷却の終わりに完成品が入らなければ、そこで待つ。
- 制御核に赤石信号を入れると、次の加工を始めない（今の加工は続ける）。
- 制御核を壊したとき、仕上げより前なら取り出した材料を返す（冷媒は戻らない）。仕上げのあと（鍛え終わったあと）なら完成品を落とす。コア・残りの材料・出力も落とす。
- 保存するのは段階・段階の中の tick・加工中の物・完成品・取り出した材料・電力・使った電力の合計。形の判定は保存せず、読み込み後の最初の tick で確かめ直す。読み込み直しても、形成の演出と音は出さない。
- 通常の電力不足で施設や周りを壊すことはない。危険は炉心のブラックホールと、ジェット・ビームの通り道。通り道の生き物は押し出し、防具を無視する大ダメージ（10 tick ごとに、照射中は40、点火と収束は16）を与えて燃やす。仕上げの衝撃波は押すだけで、傷つけない。

## サーバーとクライアント

- サーバー（`forge/JetForgeBlockEntity`）は段階・tick・止まった理由・加工中の物・完成品・形の向きを同期する。段階が変わるとすぐ送り、加工中は1秒ごとにも送る。段階の切り替わりの音（警報・点火・リングが入る音・照射の始まり・2秒ごとの脈動・仕上げ・冷却・回収）もサーバーが鳴らす。
- クライアントは、止まっていなければ段階の中の tick を自分で進める。途中で入ったプレイヤーにも、同期した段階から同じ演出が出る。
- 描画（`client/JetForgeRenderer`）、演出の進み（`client/JetForgeTimeline`）、画面の閃光・揺れ・くり返す音・粒（`client/JetForgeEffects`）、ジェットのシェーダー（`shaders/core/jet_beam`）。
- 炉心のブラックホールは重力レンズのシェーダーで光の経路をたどる。円盤の明るさの倍率と渦の筋の時計を、uniform `DiskP` に足した（既存のブラックホールは倍率1・筋なしで、見た目は変わらない）。レンズを使わないとき（設定で切った・シェーダーパック）は、黒い球と光る円盤をワールドに描く。
- ジェットは軸のまわりの立体の筒を3層重ね、専用シェーダーで流れる渦と波を描く（光暈・プラズマ・芯）。頂点ごとに「カメラから見て筒のどのくらい横か」を渡して、中心を明るく縁を消す（初版のカメラを向いた帯は、斜めから見ると平たく見えた）。シェーダーを読めなかった・シェーダーパック使用時は、色だけの加算の筒に切り替える。
- 排熱側の杯とビーム止めの熱は、宙に浮いた円板ではなく、奥の板と壁の内側の面に貼りつく光で描く。反対側のジェットは杯の内側より細く広がり、壁に刺さらない。
- 遠い（96ブロックより遠い）ときは稲妻・破片・亀裂・警告灯の光の束を省き、ジェットの分割を減らす。描画設定が「処理優先」なら光暈を省く。火花と湯気は粒子の設定で減らし、最小なら出さない。
- 素材の赤熱は、コラプサー・ビレットとインゴットでは絵そのものを熱の段階（`<id>_heat_1〜4`、tools/jet_forge_assets.py で元の絵から焼く）に差し替え、段階の間は次の絵を半透明で重ねる。赤熱の絵のない素材（データパックで足したレシピなど）は、同じ形を加算で重ねて光らせる。
- 閃光は仕上げの一瞬だけ画面を白くし、照射中は白くしない。揺れは照射中に近くで弱く、仕上げで強い。クライアント設定 `jetForgeFlash`・`jetForgeShake`（0〜1）で弱めたり切ったりできる。

## 調整しそうな所

- 電力（250 MFE/t × 60秒）と材料（ジェット凝縮体4・ネザライト1）。装備 mod の必要数が決まってから、1回で作る数を見直す。
- 影の大きさ（`JetForgeRenderer.SHADOW` = 0.85）と円盤の外径（3.6）。炉心の空気の球（半径約5.5）に収めている。
- ビームの太さの段（リングごとに 0.7 → 0.42 → 0.2）、照射の脈の周期（約1秒）、光の輪の間隔。
- 閃光の強さ（近いほど強く、64ブロックで0）と揺れの範囲（照射18ブロック、仕上げ40ブロック）。
