## 修正した問題

1. **部分チャンク未読込中の加工再開**。256セル単位の検査で、後半の未読込を検出してカーソルを戻すと、先頭の読込済みスライスで `unloaded` を解除していた。形成済みの施設の小さなチャンク範囲を毎tick確認し、未読込が1つでもあれば走査位置と無関係に停止する。ブロックの全走査やチャンクの強制読込は行わない。独立レビューの具体例は制御核(14,64,0)、back=SOUTH、チャンク(0,-1)未読込、先頭未読込セルindex383（2番目のスライス）。これは順序モデルの再現で、実機のチャンク解放試験ではない。
2. **不可視／停止中のビームダメージ**。破損、未読込、電力不足でも照射フェーズが残っているとダメージを与えていた。運転可能な点火・収束・照射中だけビームを有効にする。ブラックホールの引力は独立して継続する。
3. **保存間の進捗更新**。20tickの同期間隔中も進捗・点火状態を変更したtickでチャンクをdirtyにし、保存直後の短い再読込で古い進捗へ戻ることを防ぐ。
4. **ブラックホールの位置**。稼働済みの炉心を別方向の施設へ再形成して移動させない。元の向きを保持してから判定する。
5. **出力／冷媒**。空の出力枠にも最大スタック数を適用し、同一冷媒の複数要求は合計量を確認する。
6. **クライアント同期**。点火中も定期同期し、未読込で停止中はクライアント側の点火時計を進めない。初回同期の稼働済み炉心で生成直後の閃光を誤発生させない。
7. **重力レンズの描画枠**。32件受付に対して実描画4件という差で、受理された黒球が後から選外になる問題を修正。黒球と円盤を描くと返した分は4枠以内へ制限し、歪みだけの効果より先に描画枠へ割り当てる。上限を超えた呼出しはfalseとなり通常描画を行う。画面で5個以上を同時に見る確認は未実施。
8. **ポートと設定境界**。未読込コントローラをポート探索で強制読込しない。着火率の `long * 100` を浮動小数の割合計算に変え、設定上限付近での表示オーバーフローを避ける。

## 回帰検証の追加

## 実行を妨げる環境条件

- 1.21.1: 既存のSodiumコンパイル依存 `api.modrinth.com` が接続許可外で403。
- 1.20.1 Forge: 既存のForge依存 `maven.minecraftforge.net` が接続許可外で403。
- 1.20.1 NeoForge: 既存のEmbeddium等の依存が同じ2ドメインで403。
- Java17の自動取得はfoojay接続の403で停止したが、許可済みのOracle配布元からローカルのJDK17を用意済み。
- CI実行用のドラフトPR作成は自動承認レビューに拒否された。理由: 「レビューと準備の依頼にはPR作成の明示許可がない」。作成は実行されていない。未承認のまま別経路でPRを作成しない。
