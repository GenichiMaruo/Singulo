## 0.9.0の内容（方針: 新コンテンツより、今あるものの完成度を上げる）

作者の通しプレイは、下の修正のあとに行う。

### 1. バックパックのティア（済）
- 3段階: バックパック（12枠・段階2）→ 強化バックパック（18枠・段階3）→ 大型バックパック（24枠・段階4）。上位は1つ下を材料にして精密組立台で作る。
- 既存の「バックパックアップグレード」は12枠になる。旧版で13枠目以降に入れた物は消さない（取り出しだけでき、作業には使わない）。
- 中身が収まる大きいバックパックへは、中身を出さずに付け替えられる。収まらないものへは付け替えられない。
- 射撃型の内蔵バックパックは24枠のまま。
- GameTest: backpackTiersSetCapacity。

### 2. バランスの見直し
- 伐採の充電（済）: 固定24 → 12＋原木1本ごとに2（小さな木で約22、大きなジャングルの木で200前後）。
- 机上の検証: 全レシピを原料・時間・電力に展開して段階ごとに比べた（作業用の解析スクリプト）。段階内で極端に浮いた物は見つからなかった
  （構造用の部品が安く、コントローラやコアが高いのは意図どおり）。アンドロイドの電力は段階2の発電量に比べて小さく、制約になっていない。
  これを変えるかは、通しプレイで「電力ではなく移動・在庫・装置が制約」という今の手触りが良いかを見て決める。
- 通しプレイで見てほしい所: 生産アップグレード（段階2で原料約120）と工場式印刷ユニットの重さ、大型バックパック（段階4）の重さ、ボスの人数補正。

### 3. アンドロイドの仕上げ（済）
- 止まっている理由を出す: ステーションの電力不足・たどり着けない・素材不足・守られたブロック・作業の範囲に対象がない・置き場がいっぱい。
  アンドロイドの画面の吹き出し（赤い字）、作業指令台の注文の詳細、測量メガネを掛けたときの頭の上の印に出る。10秒続かなければ消える。
- 不具合の修正: 充電中にステーションがなくなった護衛が、充電の状態のまま止まり続けていた。自分で充電する状態へ移る。
- GameTest: stallShowsStationOutOfPower。
- 未着手: 保存と再開（OSごと終了・チャンクの読込順の違い）の検証は、既存の GameTest 以上のことはしていない。

### 4. 説明と導線のリワーク（済）
- ハンドブック: 各段階の章の先頭に「段階Nの流れ」（やることの順番・次の段階の鍵・つまずきやすい所）。前の「段階N+1へ進むには」と置き換えた。
- アンドロイドの章に「はじめての作業注文」（パンを作らせる手順と注文の画面の検索）と「止まっているとき」を足した。
- 長いページ（遺構の番人・アップグレード・加工）を段落の切れ目で分けた。
- 「進み具合」の章は、次の目標がある段階から開き、各段階のページから「段階Nの流れ」へ飛べる。
- 説明欄: 長い説明（70字以上）の13件に要約を足した。説明書5言語にバックパックのティアと止まっている理由を足した。
