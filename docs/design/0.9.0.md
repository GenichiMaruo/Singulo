## 対応環境の方針（2026-10-17 決定）

- **Minecraft 1.21.1のForge対応は0.8.1を最後とする。0.9.0以降は継続しない。**
- Minecraft 1.21.1の0.9.0以降はNeoForge版を開発・検証・公開する。

- 0.8.1の公開済みForge版を取り下げる指示ではない。
