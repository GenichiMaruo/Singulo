# 0.9.0 開発メモ

## 対応環境の方針（2026-10-17 決定）

- **Minecraft 1.21.1のForge対応は0.8.1を最後とする。0.9.0以降は継続しない。**
- Minecraft 1.21.1の0.9.0以降はNeoForge版を開発・検証・公開する。
- この決定はMinecraft 1.21.1のForge版が対象。1.20.1ブランチのForge / NeoForge対応方針は変更しない。
- 0.8.1の公開済みForge版を取り下げる指示ではない。

## 0.9.0で反映すること

- [x] 対応環境の説明を1.21.1はNeoForgeのみと明記する（README）。
- [x] 0.9.0のビルド・CI・CurseForge公開から1.21.1 Forge版を外す。0.8.1の修正を取り込む際にも、この方針を維持する。

  - 0.8.1 の Forge 版のソースは `v0.8.1` タグに残っている。

## 0.9.0の内容（方針: 新コンテンツより、今あるものの完成度を上げる）

作者の通しプレイは、下の修正のあとに行う。

### 1. バックパックのティア
- 3段階: バックパック（12枠・段階2）→ 強化バックパック（18枠・段階3）→ 大型バックパック（24枠・段階4）。上位は1つ下を材料にして作る。
- 既存の「バックパックアップグレード」は12枠になる。旧版で13枠目以降に入っていた物は消さない（取り出しだけできる、作業には使わない）。
- 中身がそのまま入る上位のバックパックへは、中身を出さずに付け替えられる。
- 射撃型の内蔵バックパックは大型と同じ24枠。

### 2. バランスの見直し
- 伐採の充電: 固定24 → 基本料金＋原木の数に比例（大きな木ほど高い）。
- ほかの数値は、変更の理由と前後の値をここに記録する。

### 3. アンドロイドの仕上げ
- 止まっている理由を見えるようにする（充電切れ・経路なし・素材不足・権限なしなど）。
- 保存と再開、チャンクの読込順の違いに対する頑丈さを確かめて直す。

### 4. 説明と導線のリワーク
- ハンドブック: 0.8.x で増えた要素（巡回・経路カード・地下研究所・試作機・作業指令台の注文）を補い、読む順を進み方に合わせる。
- 説明欄: 要約と Shift の詳細を全アイテムで見直す。
- 「次の目標」の案内と進捗の並びが、実際の進み方と合っているか確かめる。
